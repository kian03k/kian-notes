# 07 · 迁移学习

> 本章目标：学会用别人训练好的经典网络（ResNet）来跑自己的任务 —— 不从头训练，也能又快又好。
> 原始代码：`5/01、使用torchvision模型进行cifar10数据集分类.py`、`5/02、加载模型进行预测.py`

---

## 7.1 什么是迁移学习

从头训练一个深度网络需要**大量数据 + 大量算力**。**迁移学习（Transfer Learning）** 的思路是：**借用在超大数据集（ImageNet）上训练好的模型**，改一改用于自己的任务。

- 大模型在浅层学到的（边缘、纹理、形状）是**通用**的，可以直接复用；
- 通常只需**替换最后的分类层**，再用自己的小数据集**微调（fine-tune）**。

> 一句话：**站在巨人的肩膀上**。数据少也能训出好模型。

---

## 7.2 demo：ResNet50 + CIFAR-10 分类

**CIFAR-10**：10 类（飞机/汽车/鸟/猫/鹿/狗/蛙/马/船/卡车）的 32×32 彩色图，5 万训练 + 1 万测试。

```python
import torch
import torchvision

device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')

# 加载 ResNet50（num_classes=10 输出 10 类；pretrained=False 表示不加载预训练权重）
model = torchvision.models.resnet50(pretrained=False, num_classes=10).to(device)
# 想用预训练权重做迁移学习，改成 pretrained=True（新版用 weights='IMAGENET1K_V2'）

# 数据预处理
transform = torchvision.transforms.Compose([
    torchvision.transforms.ToTensor(),
    torchvision.transforms.Resize(224),          # ResNet 期望 224×224
])

train_set = torchvision.datasets.CIFAR10(root='./', train=True,  download=True, transform=transform)
test_set  = torchvision.datasets.CIFAR10(root='./', train=False, download=True, transform=transform)

train_loader = torch.utils.data.DataLoader(train_set, batch_size=8, shuffle=True)

loss_func = torch.nn.CrossEntropyLoss().to(device)
optim = torch.optim.Adam(model.parameters(), lr=0.01)

for epoch in range(1):
    for step, (x, y) in enumerate(train_loader):
        x, y = x.to(device), y.to(device)
        pre = model(x)
        loss = loss_func(pre, y)

        optim.zero_grad()
        loss.backward()
        optim.step()
    print(f'epoch={epoch}, loss={loss.item():.4f}')

torch.save(model, 'cifar10_resnet50.pth')
```

> ⚠️ 两个小坑：
> 1. `pretrained=True` 在新版 torchvision 里已**弃用**，改用 `weights=torchvision.models.ResNet50_Weights.DEFAULT`。
> 2. 原代码 `Resize(224)` 放在 `ToTensor()` **之后**，其实应该是先 Resize 再 ToTensor（顺序影响不大但规范上要调整）。

## 7.3 demo：加载模型做预测

训练好的模型可以保存下来，之后随时加载预测。

```python
import torch
import torchvision
import cv2

device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')

# 方式一：加载整个模型对象（需要模型类可见）
model = torch.load('cifar10_resnet50.pth', map_location=device)
model.eval()                                     # 切到评估模式

# 方式二（推荐）：加载权重
# model = torchvision.models.resnet50(num_classes=10)
# model.load_state_dict(torch.load('cifar10_resnet50.pth'))
# model = model.to(device); model.eval()

img = cv2.imread('data/002.jpg')
img = cv2.resize(img, (224, 224))
img = img.reshape(-1, 3, 224, 224)                # → (N, C, H, W)
img = img / 255.0                                 # 归一化到 [0,1]

test = torch.tensor(img, dtype=torch.float32).to(device)

with torch.no_grad():                             # 推理不需要梯度，省显存
    pre = model(test)
    pre_y = torch.argmax(pre, dim=1)

print('预测类别索引：', pre_y.item())
```

> 💡 预测时的三个"对齐"：**尺寸要对齐（resize）、通道顺序要对齐（NCHW）、数值范围要对齐（/255 或标准化）** —— 训练怎么处理，预测就得怎么处理。

## 7.4 进阶：迁移到自己数据

把经典网络改成自己的分类器（比如**果蔬分类**这类毕设场景）：

```python
import torchvision
import torch

# ① 拿一个预训练骨干
model = torchvision.models.resnet50(weights='IMAGENET1K_V2')

# ② 冻结前面的卷积层（只训练最后的分类头）
for p in model.parameters():
    p.requires_grad = False

# ③ 替换最后的全连接层为你的类别数（比如 37 类果蔬）
num_classes = 37
model.fc = torch.nn.Linear(model.fc.in_features, num_classes)

# ④ 只优化新的 fc 层
optim = torch.optim.Adam(model.fc.parameters(), lr=1e-3)
```

**训练策略**：

- **冻结骨干、只训分类头**：数据少时首选，快且不易过拟合；
- **解冻部分层微调**：数据较多时，用更小的学习率整体微调。

> 这就是"迁移学习"最实用的形态：**一个预训练骨干 + 换掉分类头**，几十行代码就能在自己的小数据集上获得不错效果。

## 本章小结

| 概念 | 要点 |
| --- | --- |
| 迁移学习 | 复用预训练模型，换分类头 + 微调 |
| 加载模型 | `torch.load` / `load_state_dict`，预测时 `eval()` + `no_grad()` |
| 数据对齐 | 尺寸、通道顺序 NCHW、数值范围，训练/预测必须一致 |
| 微调策略 | 数据少→冻结骨干；数据多→小学习率整体微调 |
