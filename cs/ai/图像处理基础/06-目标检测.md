# 06 · 目标检测

> 本章目标：从"识别一张图里是什么"升级到"找出图里**所有**物体**在哪里**、**是什么**"，了解主流算法从 R-CNN 到 YOLO 的演进。
> 讲义：目标检测（PPT）

---

## 6.1 目标检测是什么

CV 里有三个基础任务，难度递增：

| 任务 | 输入 | 输出 | 层级 |
| --- | --- | --- | --- |
| **图像分类** | 一张图（通常一个物体） | 是什么 | 图像级 |
| **目标检测** | 一张图（多个物体） | 每个物体的**位置 + 类别** | 物体级 |
| **图像分割** | 一张图 | 每个**像素**属于哪类 | 像素级 |

目标检测要回答两个问题：**"在哪里？"（定位）** 和 **"是什么？"（分类）**。

**四大难点**：分类、定位、大小（目标尺寸差异大）、形状（形态各异）。

**应用**：人脸检测、自动驾驶、医学影像、安防……

**基本过程**（传统思路）：滑窗选候选区域 → 提特征 → 分类 → 合并框。

## 6.2 数据标注

训练检测模型需要**带标注的数据** —— 每张图 + 每个物体的**边界框（bounding box）**和类别。

### 常用数据集

| 数据集 | 类别 | 规模 | 标注格式 |
| --- | --- | --- | --- |
| **Pascal VOC** | 20 类 | VOC2007：9963 张 | XML |
| **COCO** | 80 类 | 20 万张，50 万+ 标注 | JSON |

### 边界框坐标的三种表示法（重点，容易混）

```text
① Pascal VOC：  [x_min, y_min, x_max, y_max]     # 左上角 + 右下角
② COCO：        [c_x, c_y, width, height]         # 中心点 + 宽高
③ YOLO：        [class, c_x, c_y, w, h]           # 类别 + 归一化中心点/宽高
```

> ⚠️ YOLO 格式里 `c_x, c_y, w, h` **都是相对整图的归一化值（0~1）**，不是像素值。转换时注意乘/除图像宽高。

### 标注工具

**labelImg**：`pip install labelImg`，然后终端敲 `labelimg` 启动，画框、选类别、导出即可。

## 6.3 经典算法演进

目标检测分两大流派：**Anchor-based**（一阶段 / 二阶段）和 **Anchor-free**。

### 二阶段（Two-stage）：先找候选，再分类

**① R-CNN（2014，开山之作）**

四步：候选区域（Selective Search）→ CNN 提特征 → SVM 分类 → 边框回归微调。

- 缺点：**慢**（每张图 2k 个候选框都要过 CNN），四模块分开训练。

**② SPP-Net（2014）**

- 改进：**共享卷积计算 + 空间金字塔池化**，速度比 R-CNN 快 24~102 倍。
- 缺点：仍无法微调卷积层，多阶段训练。

**③ Fast R-CNN（2015）**

- 改进：SSP Layer → **RoI Pooling**；提出**多任务损失**（分类 + 回归一起训练）。
- 提速：训练快 9 倍，推理快 213 倍。
- 缺点：候选框生成（Selective Search）仍是瓶颈。

**④ Faster R-CNN（2016）**

- 核心创新：**RPN（Region Proposal Network）** —— 用网络自己生成候选框，和检测网络共享卷积特征。
- 用**锚框（anchors）**解决尺度问题：3 种尺寸 × 3 种比例 = 9 个预定义 anchor。
- 特点：**精度高、速度慢**，Two-stage 的巅峰。

### 一阶段（One-stage）：直接回归，更快

**⑤ SSD（2016）**：多尺度特征图上直接预测，速度快，接近实时。

**⑥ YOLO（You Only Look Once，2016，一阶段开山之作）**

- 核心思想：把检测**当成回归问题**，一个 CNN 直接预测框和类别概率。
- 演进：
  - **YOLOv2（2017）**：引入 anchor，416×416 输入，13×13 特征图。
  - **YOLOv3（2018）**：多尺度预测，Redmon 封山之作。
  - **YOLOv4（2020）**：大量"免费技巧"（Bag-of-Freebies）+ 少量计算换精度（Bag-of-Specials），单卡可训。
  - **YOLOv5（2020，Ultralytics）**：PyTorch 实现，4 个规格（s/m/l/x），轻量快。
  - **YOLOX（2021，旷视）**：Anchor-free 化的 YOLO。

> 一句话对比：**Two-stage 精度高但慢，One-stage 快精度略低** —— YOLO 系列把"快且准"做到了极致。

### Anchor-free

不用预定义锚框，直接预测：

- **基于关键点**：先检测左上角 + 右下角，再组合成框 → **CornerNet**
- **基于中心**：直接预测中心区域 + 边界 → **FCOS**

> Anchor-free 的好处：超参少、框更简洁，是近年趋势。

## 6.4 实战：YOLOv8 快速上手

用 **Ultralytics** 版 YOLO 几行代码完成检测/分类：

```bash
pip install ultralytics
```

```python
from ultralytics import YOLO

# 先用官方预训练权重跑推理（检测）
model = YOLO('yolov8n.pt')          # n/s/m/l/x，n 最小最快
results = model('image.jpg')        # 直接预测
results[0].show()                   # 显示带框的图
results[0].save('out.jpg')          # 保存

# 训练自己的数据集（分类任务示例）
# cls_model = YOLO('yolov8n-cls.pt')
# cls_model.train(data='my_dataset', epochs=10, imgsz=224)
```

**训练产物解读**（`runs/` 目录下）：

| 文件 | 含义 |
| --- | --- |
| `weights/best.pt` | 效果最好的权重 |
| `results.png` / `results.csv` | 训练过程曲线（loss、精度） |
| `confusion_matrix.png` | 混淆矩阵（哪类容易混） |
| `train_batch*.jpg` | 训练样本可视化 |
| `val_batch*_pred.jpg` | 验证集预测效果 |
| `args.yaml` | 本次训练的完整参数 |

## 本章小结

| 阶段 | 代表算法 | 特点 |
| --- | --- | --- |
| 二阶段 | R-CNN → SPP → Fast → **Faster R-CNN** | 精度高、慢；RPN + anchors |
| 一阶段 | SSD、**YOLO** v1~v5 | 快；YOLO 把检测变回归 |
| Anchor-free | CornerNet、FCOS、YOLOX | 免锚框，趋势 |

**记忆主线**：`R-CNN（慢） → Fast（共享卷积） → Faster（RPN 自己出框）`，同时 `YOLO（一步到位，快）` 并行发展。

**实战**：Ultralytics YOLO 三行代码即可推理；换数据集可微调（迁移学习，见下一章）。
