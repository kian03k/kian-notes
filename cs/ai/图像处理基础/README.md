# 图像处理基础 · 学习笔记（计算机视觉入门）

> 一套从 **OpenCV 图像处理 → 机器学习 → 深度学习 → 目标检测** 的 CV 入门路线。
> 由原课程练习代码 + 讲义（PPT/PDF）**整理、归纳、重写**而成 —— 不是把 `.py` 堆进来，而是**以"讲课"的方式**重新组织：每节先讲清「是什么 / 为什么」，再给**可运行的精简 demo**（带逐行注释），最后点出**参数要点和常见坑**。

## 环境准备

```bash
# 建议 Python 3.8+（原课程基于 3.8）。按需安装：
pip install opencv-python numpy matplotlib        # 阶段一
pip install scikit-learn pandas joblib            # 阶段二
pip install torch torchvision                     # 阶段三（GPU 版去 pytorch.org 选对应 cuda）
```

- **图像处理**：`opencv-python` + `numpy` + `matplotlib`
- **机器学习**：`scikit-learn`（`sklearn`）+ `pandas` + `joblib`
- **深度学习**：`torch` + `torchvision`（有 N 卡装 CUDA 版，没卡自动用 CPU）
- 想省事可装 Anaconda，常用库基本自带。

## 怎么用这套笔记

1. **按顺序读**：`01 → 09` 是递进的，前一章是后一章的基础。
2. **边读边跑**：每个 demo 都可直接运行。先看代码跑通，再回头理解原理。
3. **跑不动就先看**：OpenCV 的 demo 需要显示窗口（本地跑），纯看也没问题。
4. 遇到 ⚠️ 标记的是**常见坑**，踩过，值得留意。

> 一句话：这套笔记的目标不是"存下来"，而是"**看得懂、跑得起来、学得进去**"。
