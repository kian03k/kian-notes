## 4.1 机器学习是什么

**机器学习（ML）**：让计算机从数据里**自动找出规律（模式）**，进而对未知数据做预测，而不是靠人写死规则。

按**样本有没有标签**，分两大类：

| 类型 | 数据 | 任务 | 典型算法 |
| --- | --- | --- | --- |
| **监督学习** | 有标签 `(x, y)` | 分类、回归 | 逻辑回归、KNN、SVM、决策树、随机森林 |
| **无监督学习** | 只有 `x`，无 `y` | 聚类 | K-Means、DBSCAN、层次聚类、谱聚类 |

按**输出是什么**：

- **回归（Regression）**：预测**连续值**（房价、销量）。"最佳拟合" —— 用一条线/面逼近数据。
- **分类（Classification）**：预测**离散类别**（是/否、猫/狗）。
- **聚类（Clustering）**：把无标签数据按相似性分组，"物以类聚"。

> 一句话记：**有 y 叫监督，没 y 叫无监督；输出是数叫回归，是类叫分类。**

---

## 4.2 机器学习流程

一个标准流程大致是：**数据 → 清洗 → 特征工程 → 划分 → 训练 → 评估 → 保存**。

### ① 数据

来源：用户行为、业务数据、第三方数据。学习阶段多用公开数据集（`sklearn.datasets`）。

```python
from sklearn.datasets import load_iris, load_digits
iris = load_iris()          # 鸢尾花：150 样本 × 4 特征，3 类
digits = load_digits()      # 手写数字：1797 样本 × 64 特征，10 类
```

### ② 特征工程

**特征工程** = 把原始数据变成"算法更好用"的数值特征。包括**特征提取、预处理、降维**。

**预处理（数值无量纲化）** —— 最常用的是**标准化**：

```python
from sklearn.preprocessing import StandardScaler, MinMaxScaler

std = StandardScaler()          # 标准化：均值 0、方差 1（最常用）
x = std.fit_transform(x)

# 归一化：把值压到 [0,1]
mm = MinMaxScaler()
x = mm.fit_transform(x)
```

> ⚠️ **标准化的坑**：训练集用 `fit_transform`，测试集**只能 `transform`**（用训练集的均值/方差），否则数据泄漏。原代码里 `x = std.fit_transform(x)` 后测试集也用同一 std，是对的。

### ③ 划分数据集

```python
from sklearn.model_selection import train_test_split
train_x, test_x, train_y, test_y = train_test_split(x, y)
# 默认 75% 训练 / 25% 测试，可加 test_size=0.2
```

### ④ 模型评估

**回归指标**：

| 指标 | 含义 |
| --- | --- |
| MSE / RMSE 均方(根)误差 | 预测值与真实值差的平方均值 |
| MAE 平均绝对误差 | 绝对误差的平均 |
| R² 决定系数 | 越接近 1 拟合越好 |

**分类指标**：

| 指标 | 含义 |
| --- | --- |
| 准确率 Accuracy | 分对的样本 / 总数 |
| 精确率 Precision | 预测为正里，真正为正的比例 |
| 召回率 Recall | 真正为正里，被找出来的比例 |
| F1 | 精确率与召回率的权衡 |
| 混淆矩阵 | 各类别分对/分错的数量表 |

**聚类指标**：轮廓系数 `silhouette_score`（越大越好）、Calinski-Harabasz、戴维森堡丁指数 DBI（越小越好）。

> **过拟合 / 欠拟合**：
> - 过拟合：训练好、测试差 → 加数据、降复杂度、正则化、集成学习
> - 欠拟合：训练测试都差 → 加特征、加复杂度、减正则

## 4.3 回归

### 线性回归（最基础的监督学习）

目标是找一条直线/超平面 `y = w·x + b`，让预测值和真实值差得最小。

```python
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.datasets import load_diabetes      # 糖尿病数据集（13 特征）
import joblib

data = load_diabetes()
x, y = data.data, data.target

std = StandardScaler()
x = std.fit_transform(x)

train_x, test_x, train_y, test_y = train_test_split(x, y)

model = LinearRegression()
model.fit(train_x, train_y)                     # 训练

# 评估
print('训练集 MAE:', mean_absolute_error(train_y, model.predict(train_x)))
print('测试集 MAE:', mean_absolute_error(test_y, model.predict(test_x)))
print('权重 w:', model.coef_)
print('偏置 b:', model.intercept_)

joblib.dump(model, 'lr.pkl')                    # 保存模型
```

> ⚠️ **注意**：原课程用的 `load_boston()` 在新版 scikit-learn 中**已移除**（伦理争议）。替换为 `load_diabetes()` / `fetch_california_housing()` 即可，写法完全一样。

### 回归的"变种"（正则化）

在线性回归的损失函数上加**正则项**，防止过拟合：

```python
from sklearn.linear_model import Lasso, Ridge, ElasticNet, RidgeCV

Ridge()        # 岭回归：加 L2 正则
Lasso()        # 套索：加 L1 正则（能把不重要的特征权重压成 0）
ElasticNet()   # 弹性网：L1 + L2 结合
RidgeCV()      # 带交叉验证的岭回归，自动选超参
```

| 模型 | 正则 | 特点 |
| --- | --- | --- |
| Ridge 岭回归 | L2 | 权重平滑收缩 |
| Lasso | L1 | 可做特征选择（稀疏） |
| ElasticNet | L1+L2 | 两者结合 |

### 回归案例：数据标准化 + 预测

```python
import pandas as pd
from sklearn.linear_model import LinearRegression
from sklearn.preprocessing import StandardScaler
import numpy as np

train = pd.read_csv('data/train.csv')
test  = pd.read_csv('data/test.csv')
train = train.drop('id', axis=1)          # 去掉编号列
test  = test.drop('id', axis=1)

x = train.iloc[:, train.columns != 'y']   # 特征
y = train.iloc[:, train.columns == 'y']   # 标签

std = StandardScaler()
x = std.fit_transform(x)
test = std.transform(test)                # 测试集只 transform！

model = LinearRegression().fit(x, y)
pred = np.floor(model.predict(test))      # 预测并取整
print('预测结果：', pred)
```

## 4.4 分类

### 逻辑回归（名字带"回归"，其实是分类）

它在 `y = w·x + b` 外**套一个 Sigmoid 函数**，把输出压到 `[0,1]`，当作"属于正类的概率"，再按 0.5 阈值分类。

```python
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import precision_score, confusion_matrix
from sklearn.datasets import load_iris
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import train_test_split

iris = load_iris()
x, label = iris.data, iris.target

std = StandardScaler()
x = std.fit_transform(x)
train_x, test_x, train_label, test_label = train_test_split(x, label)

clf = LogisticRegression(max_iter=1000)
clf.fit(train_x, train_label)

print('测试准确率:', precision_score(test_label, clf.predict(test_x), average='micro'))
print('混淆矩阵:\n', confusion_matrix(test_label, clf.predict(test_x)))
```

> 关键理解：**Sigmoid** 把 `(-∞, +∞)` 映射到 `(0, 1)`，`sigmoid(z) > 0.5` 即预测为正类。这就是从"线性回归"跨到"分类"的那一步。

### 其他常用分类器（一行切换）

sklearn 最大的好处是**接口统一**：`fit` / `predict`，换模型只需换一行。

```python
from sklearn.neighbors import KNeighborsClassifier      # KNN
from sklearn.svm import SVC                             # 支持向量机
from sklearn.naive_bayes import GaussianNB              # 朴素贝叶斯
from sklearn.tree import DecisionTreeClassifier         # 决策树
from sklearn.ensemble import RandomForestClassifier, AdaBoostClassifier  # 集成

for name, clf in [('KNN', KNeighborsClassifier()),
                  ('SVM', SVC()),
                  ('NB',  GaussianNB()),
                  ('DT',  DecisionTreeClassifier()),
                  ('RF',  RandomForestClassifier()),
                  ('AdaBoost', AdaBoostClassifier())]:
    clf.fit(train_x, train_label)
    acc = precision_score(test_label, clf.predict(test_x), average='micro')
    print(f'{name}: {acc:.3f}')
```

### 这些算法分别是什么（讲义要点）

| 算法 | 一句话 | 关键参数 |
| --- | --- | --- |
| **KNN** | 看最近的 K 个邻居，少数服从多数 | `n_neighbors`（K 值）、距离度量 |
| **SVM** | 找最优决策边界，让两类间隔最大 | `C`（容错）、`kernel`（linear/rbf/poly） |
| **朴素贝叶斯** | 用贝叶斯公式算概率，假设特征独立 | `alpha`（拉普拉斯平滑） |
| **决策树** | 不断按特征"分叉"，像一棵问答题的树 | `criterion`（gini/entropy）、`max_depth` |
| **随机森林** | 很多棵决策树投票（集成学习） | `n_estimators` |

> - **SVM 的核函数**：线性不可分时，用 `rbf` 核把数据映射到高维再找超平面。
> - **朴素贝叶斯**：文本分类的经典算法（配合 `CountVectorizer` / `TfidfVectorizer` 做词袋特征）。
> - **决策树**：用"信息增益/基尼系数"选择分裂特征；ID3/C4.5/CART 是三代算法。
> - **随机森林**：集成学习代表，"三个臭皮匠顶个诸葛亮"，Bagging 并行训练多棵树。

## 4.5 聚类

### K-Means（最常用的聚类）

流程：**随机选 K 个中心 → 把样本分给最近的中心 → 重算各簇均值作为新中心 → 重复直到收敛**。

```python
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score
from sklearn.datasets import make_blobs, make_moons, make_circles

x, _ = make_moons(n_samples=1000)          # 造两个月牙形数据

plt.subplot(1, 2, 1)
plt.scatter(x[:, 0], x[:, 1])              # 原始数据

km = KMeans(n_clusters=8)                  # 聚成 8 簇
km.fit(x)

plt.subplot(1, 2, 2)
plt.scatter(x[:, 0], x[:, 1], c=km.predict(x))   # 按簇上色
plt.show()

print('轮廓系数:', silhouette_score(x, km.labels_))   # 越大越好
```

### 经典案例：用 K-Means 压缩图片

**思路**：把图像所有像素当成数据点聚类。原本每个像素是 24 位（RGB 各 8 位），聚成 K 个颜色后，每个像素只需表示"属于哪个颜色"，颜色数从百万级降到 K 个 → **压缩**。

```python
import cv2
import numpy as np
from sklearn.cluster import KMeans

img0 = cv2.imread('data/lena.png')       # (h, w, c)
h, w, c = img0.shape
img = img0.reshape(h * w, c)             # 拉平成 (像素数, 3)

km = KMeans(n_clusters=8)                # 只用 8 种颜色
km.fit(img)

# 每个像素用"它所属簇的中心颜色"替换
new_img = km.cluster_centers_[km.labels_].astype(np.uint8).reshape(h, w, c)

cv2.imshow('原图', img0)
cv2.imshow('K=8 压缩', new_img)
cv2.waitKey(0); cv2.destroyAllWindows()
```

> 这就是深度学习"**词向量/量化**"思想的雏形 —— 用少量代表点替换大量原始数据。

### 其他聚类算法

| 算法 | 类型 | 特点 |
| --- | --- | --- |
| **K-Means** | 基于划分 | 快，但需指定 K，只擅长"凸"簇 |
| **AgglomerativeClustering** | 层次 | 自底向上合并，树状结构 |
| **DBSCAN** | 密度 | 能发现任意形状，抗噪声，不用指定 K |
| **MeanShift** | 密度 | 只需带宽参数，自动定簇数 |
| **SpectralClustering** | 图 | 适合非凸簇 |
| **GaussianMixture (GMM)** | 概率模型 | 用 EM 算法，给出概率归属 |

```python
from sklearn.cluster import DBSCAN, AgglomerativeClustering
km = DBSCAN(eps=0.05)        # 密度聚类：eps 是邻域半径
km.fit(x)
```

> 回顾讲义 **EM 算法**：一种"含隐变量时的最大似然估计"迭代法，**E 步**（求期望）和 **M 步**（最大化）交替，GMM 就是它的典型应用。

## 4.6 模型保存与加载

```python
import joblib

joblib.dump(model, 'model.pkl')      # 保存
model = joblib.load('model.pkl')     # 加载

# 加载后预测要注意：输入要经过和训练时一样的预处理！
```

> ⚠️ **预测时的经典坑**：训练时对特征做了标准化，预测新样本时**必须用同一个 `StandardScaler` 再 transform 一次**，否则结果全错。所以标准化器也要一起保存：

```python
joblib.dump(std, 'std.pkl')          # 连标准化器一起存
# 预测时：
x_new = std.transform(x_new)         # 先标准化
label = model.predict(x_new)
```
