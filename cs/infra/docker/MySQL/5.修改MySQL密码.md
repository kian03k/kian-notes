# 1. 修改配置里的密码，会发生什么？
你现在的配置：
```yaml
environment:
  MYSQL_ROOT_PASSWORD: "MyStrongPassword123!"
```

**这个环境变量，只有第一次创建容器、第一次初始化数据时有效！**

一旦你第一次 `up` 之后：
- **数据已经生成在 ./data 文件夹里**
- 密码已经固化在 MySQL 内部
- **你再改配置文件里的密码 → 完全无效！**
- MySQL 不会重新初始化
- 不会重新安装
- 不会重新下载镜像

# 2. 那我想改密码，应该怎么做？
有两种方法，**推荐第一种（最干净）**

## 方法 A：清空数据，重新初始化（最简单、最推荐）
你现在只是测试环境，没有重要数据，直接这样：

### 步骤 1：停止并删除容器
```bash
docker compose down
```

### 步骤 2：删除数据文件夹（关键！）
```bash
sudo rm -rf ./data
```

### 步骤 3：在 docker-compose.yml 里改成新密码
```yaml
MYSQL_ROOT_PASSWORD: "你的新密码"
```

### 步骤 4：重新启动
```bash
docker compose up -d
```

✅ **新密码立即生效**
✅ **干净、无坑**

---

## 方法 B：不删数据，进入容器改密码（有数据时用）
```bash
docker exec -it mysql-prod mysql -uroot -p
```
输入旧密码登录后执行：
```sql
ALTER USER 'root'@'%' IDENTIFIED BY '新密码';
```
这个方法**不会影响配置文件**。
