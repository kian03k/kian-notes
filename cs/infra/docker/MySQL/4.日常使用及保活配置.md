既然你已经全部安装好了，那日常的“开关”和“保活”确实是最重要的。针对你的需求，我整理了三套不同场景下的操作方案，从最基础的命令到“一劳永逸”的开机自启都有：

### 🛠️ 日常启动与关闭（手动控制）

这是最常用的方式，适合你正在开发、需要临时关闭数据库节省资源，或者重启数据库时。

**前提**：你需要进入你的项目目录。

1.  **进入项目目录**
    ```bash
    cd ~/docker-env/mysql
    ```

2.  **启动服务**
    如果你之前已经启动过，只是关机了，直接运行：
    ```bash
    docker compose up -d
    ```
    *解释：`-d` 表示后台运行（Detached mode），不会占用你的终端窗口。*

3.  **停止服务**
    当你不需要数据库，或者想彻底关闭它以释放内存时：
    ```bash
    docker compose down
    ```
    *解释：这会停止并删除容器，但**不会**删除你的数据（因为数据在挂载目录里）。*

4.  **重启服务**
    如果你修改了配置文件（`conf/my.cnf`），想让配置生效：
    ```bash
    docker compose restart
    ```

### 🚀 如何实现持续运行（开机自启）

你可能希望：**“只要我打开电脑，MySQL 就自动在后台运行，不用我每次敲命令。”**

这里有两种方案，取决于你的 Docker 环境配置。

#### 方案 A：Docker Desktop 自动启动（最简单，推荐）

如果你安装的是 **Docker Desktop**（带有图形界面的那个），它自带了一个非常方便的设置。

1.  **设置 Docker Desktop**：
    *   打开 Docker Desktop 设置。
    *   找到 **“General”** 选项。
    *   勾选 **“Start Docker Desktop when you log in”**（登录时启动）。
    *   勾选 **“Start Docker containers automatically”**（自动启动容器）。

2.  **设置容器的重启策略**：
    你需要告诉 Docker：“如果电脑重启了，你要自动拉起这个容器”。
    修改你的 `docker-compose.yml` 文件：
    ```yaml
    services:
      mysql:
        image: mysql:8.0.33
        restart: always  # <--- 加上这一行！
        # ... 其他配置
    ```
    *解释：`always` 表示无论什么情况（除非你手动 stop），Docker 都会尝试重启这个容器。*

3.  **生效**：
    执行一次 `docker compose up -d`。以后只要你开机并启动了 Docker Desktop，MySQL 就会自动在后台运行。

#### 方案 B：WSL2 系统级自启（进阶，适合极客）

如果你没有 Docker Desktop，或者希望 WSL2 一启动就自动运行容器（即使不打开 Docker Desktop），可以配置 systemd。

1.  **创建服务文件**：
    在 WSL2 终端执行：
    ```bash
    sudo vim /etc/systemd/system/docker-mysql.service
    ```

2.  **填入配置**：
    ```ini
    [Unit]
    Description=Docker Compose MySQL Service
    Requires=docker.service
    After=docker.service

    [Service]
    # 替换成你的实际用户名和项目路径
    WorkingDirectory=/home/<你的用户名>/docker-env/mysql
    ExecStart=/usr/local/bin/docker compose up -d
    ExecStop=/usr/local/bin/docker compose down
    TimeoutSec=0
    RemainAfterExit=yes
    GuessMainPID=no

    [Install]
    WantedBy=multi-user.target
    ```

3.  **启用服务**：
    ```bash
    sudo systemctl daemon-reload
    sudo systemctl enable docker-mysql.service
    sudo systemctl start docker-mysql.service
    ```
    *解释：这样配置后，只要 WSL2 启动（通常是随 Windows 启动），这个服务就会自动运行。*

### 🧹 日常维护小技巧

1.  **查看状态**
    想知道数据库还在不在运行？
    ```bash
    docker compose ps
    ```
    *看到 `Up (healthy)` 就是最完美的状态。*

2.  **查看实时日志**
    如果连不上数据库，看看发生了什么：
    ```bash
    docker compose logs -f mysql
    ```
    *按 `Ctrl+C` 退出日志查看。*

3.  **进入数据库**
    不想用客户端软件，只想快速查个数据：
    ```bash
    docker exec -it mysql-prod mysql -u root -p
    ```

### 📌 总结建议

*   **日常开发**：用 `docker compose up -d` 和 `docker compose down` 手动控制。
*   **长期运行**：修改 `docker-compose.yml` 加上 `restart: always`，并确保 Docker Desktop 设置了开机自启。这是最省心、最标准的做法。
