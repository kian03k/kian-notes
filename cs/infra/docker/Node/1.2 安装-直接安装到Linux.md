# 最终工程化安装教程（系统级，干净、标准、稳定）
## 1. 先清理旧环境（避免冲突）
```bash
sudo apt remove -y nodejs npm
rm -rf ~/.nvm ~/.npm ~/.pnpm ~/.local/share/pnpm-store
```

## 2. 安装 nvm（最新稳定版 v0.40.3）
```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
```
使用git替代
```
git clone https://gitee.com/mirrors/nvm.git ~/.nvm
cd ~/.nvm 
git checkout v0.40.3 
cd ~
```
## 3. 立即加载 nvm（不用重启终端）
```bash
# 设置淘宝镜像，让下载速度飞起 
export NVM_NODEJS_ORG_MIRROR=https://npmmirror.com/mirrors/node

export NVM_DIR="$HOME/.nvm"
[ -s "$NVM_DIR/nvm.sh" ] && \. "$NVM_DIR/nvm.sh"
[ -s "$NVM_DIR/bash_completion" ] && \. "$NVM_DIR/bash_completion"
```
**告诉系统 nvm 安装在哪个目录。**
**如果 nvm.sh 这个文件存在，就执行它，把 nvm 注入到当前终端里。**
**给 nvm 加命令补全功能，按 Tab 能提示版本。**
## 4. 安装 Node.js 24 LTS（最新官方稳定版）
```bash
nvm install 24 
nvm alias default 24
```

验证：
```bash
node -v  # v24.15.0
npm -v   # 11.x+
```

## 5. 启用 pnpm（Node 官方推荐：corepack 方式，最标准）
Node 24 自带 corepack，**这是行业标准、官方推荐**。

```bash
corepack enable
corepack prepare pnpm@latest --activate
```
设置默认版本（永久生效）
验证：
```bash
pnpm -v
```

## 6. 工程化配置（国内镜像 + 缓存路径 + 权限干净）
这一步是**专业前端必须配置**，否则安装慢、占空间、权限乱。

```bash
# pnpm 国内镜像
pnpm config set registry https://registry.npmmirror.com

# 统一缓存路径（干净、可备份）
pnpm config set store-dir ~/.local/share/pnpm-store

# 禁用幽灵依赖（工程化安全）
pnpm config set strict-peer-dependencies true
# **开启严格依赖检查，杜绝 “幽灵依赖”，保证项目上线不崩。**
# 什么是幽灵依赖？（最关键的工程化坑）
#npm/yarn 会偷偷把**深层依赖暴露给你**，你可以直接 import 没在 package.json 里写过的包。
#**本地能跑 → 上线就报错。**
# 这行配置的作用：不允许你使用未声明的依赖，从根源避免上线崩溃。
```

## 7. 永久写入环境变量（新开终端直接用）
```bash
# 如果你用 bash
echo 'export NVM_DIR="$HOME/.nvm"' >> ~/.bashrc
echo '[ -s "$NVM_DIR/nvm.sh" ] && \. "$NVM_DIR/nvm.sh"' >> ~/.bashrc
echo '[ -s "$NVM_DIR/bash_completion" ] && \. "$NVM_DIR/bash_completion"' >> ~/.bashrc
echo 'export PNPM_HOME="$HOME/.local/share/pnpm"' >> ~/.bashrc
echo 'export PATH="$PNPM_HOME:$PATH"' >> ~/.bashrc

# 如果你用 zsh（把上面 ~/.bashrc 换成 ~/.zshrc 即可）
```

立即生效：
```bash
source ~/.bashrc
```

如果不写需要每次
```
export NVM_DIR="$HOME/.nvm" \. "$NVM_DIR/nvm.sh" \. "$NVM_DIR/bash_completion"
```
