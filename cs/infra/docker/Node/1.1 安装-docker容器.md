# 先回答你最重要的疑问（必须懂）
## 问：为什么不直接挂载 `~/` 整个用户目录？
### 答案（工程化安全原则）：
1. **安全风险极大**
   容器能访问你**所有私密文件**（.ssh、密钥、配置、密码、证书），一旦容器被攻击，你整个系统裸奔。

2. **权限灾难**
   容器内 root 会随意修改你宿主机文件权限，导致：
   - 桌面文件打不开
   - 配置被篡改
   - 项目文件变成 root 只读

3. **性能下降**
   Docker 监听整个目录文件变化，巨卡。

4. **污染不可控**
   容器内工具可能误写、误删你主机配置。

---

# 正确工程化原则：
**只挂载「代码目录」，不挂载「系统配置目录」**
→ 所以统一挂载：**~/workspace**
（你的所有项目、代码、git 仓库都放这里，安全、干净、隔离）

# 最终版 · Node 24 LTS + pnpm 环境（一次配完，永远不动）

~/docker-env/

## 1. 创建目录
```bash
mkdir -p ~/docker-env/node
cd ~/docker-env/node
```

## 2. 创建 Dockerfile（环境配置）
```bash
vim Dockerfile
```

写入：
```dockerfile
FROM node:24.15.0-alpine

# 安装工具 + 时区
RUN apk add --no-cache git bash tzdata \
    && cp /usr/share/zoneinfo/Asia/Shanghai /etc/localtime

# 国内镜像加速
RUN npm config set registry https://registry.npmmirror.com

# 安装 pnpm（行业主流）
RUN npm install -g pnpm

WORKDIR /app
EXPOSE 5173
CMD ["bash"]
```

## 3. 创建 docker-compose.yml（最终版，支持所有 ~/workspace 项目）
```bash
vim docker-compose.yml
```

写入（**最标准、最安全、最工程化**）：
```yaml
services:
  node24:
    build: .
    container_name: node24
    restart: no
    tty: true
    stdin_open: true

    environment:
      TZ: Asia/Shanghai

    ports:
      - "5173:5173"   # vue3 / vite
      - "3000:3000"   # node 服务
      - "4173:4173"   # 备用

    volumes:
      # 【关键】只挂载代码目录，不挂载私密文件
      - ~/workspace:/app

      # pnpm 全局缓存（所有项目共享，极快）
      - pnpm_store:/root/.local/share/pnpm/store

volumes:
  pnpm_store:
```

---

# 4. 一键启动环境
```bash
docker compose build
docker compose up -d
```

---

# 5. 进入 Node 环境（你以后只用这一条）
```bash
docker compose exec node24 bash
```

进入后：
```bash
node -v   # v24.15.0 LTS
pnpm -v   # 最新版
git --version
```

# 6. 以后所有项目都这样用（任意项目都支持）
你的项目必须放在：
```
~/workspace/xxx项目
```

进入容器后：
```bash
cd /app        # 直接看到所有项目
cd 你的项目名
pnpm install
pnpm dev --host 0.0.0.0
```

浏览器打开：
```
http://localhost:5173
```
