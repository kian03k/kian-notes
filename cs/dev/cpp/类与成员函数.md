# 类与成员函数

> 从一份 C++ 入门练习里提炼：类的定义、成员函数的「类内声明 + 类外定义」，以及顺带的 `vector` 基础。
> 参数怎么传（值 / 指针 / 引用）见 [[传值方式]]。

## 一、类的定义：数据成员 + 成员函数声明

```cpp
#include <iostream>
using namespace std;

class Box {
public:                              // 访问修饰符
    double length;                   // 数据成员
    double breadth;
    double height;
    double get(void);                // 成员函数「声明」（类内，只写签名）
    void set(double len, double bre, double hei);
};
```

- **`class` 的成员默认 `private`**，所以必须写 `public:` 才能在类外访问；`struct` 默认 `public`（其余几乎一样）。
- 类内只放**声明**（结尾带分号），函数体可以拿到类外写 → 见下。

## 二、成员函数「类外定义」：`::` 作用域解析符

```cpp
double Box::get(void) {
    return length * breadth * height;
}
void Box::set(double len, double bre, double hei) {
    length  = len;
    breadth = bre;
    height  = hei;
}
```

- 语法是 `返回类型 类名::函数名(参数)`。`Box::` 告诉编译器"这是 Box 的成员函数"——
  **只有带上它，函数体内才能直接写 `length` 这样的成员名**。
- ⚠️ 忘写 `Box::` → 编译器当成**普通全局函数**，里面的 `length` 就"找不到"，报未声明标识符。
- 若**直接在类内写函数体**，该函数会**隐式 `inline`**，适合短小函数（编译器也可能自行决定是否内联）。

## 三、实例化与访问

```cpp
int main() {
    Box Box1;
    Box1.height  = 5.0;                        // 直接改公有成员
    Box1.length  = 6.0;
    Box1.breadth = 7.0;
    cout << "Box1's volume:" << Box1.height * Box1.length * Box1.breadth << endl;

    Box Box3;
    Box3.set(16.0, 8.0, 12.0);                 // 走 set 接口
    cout << "Box3's volume:" << Box3.get() << endl;   // 走 get 接口
}
```

- 两种风格并存：**直接访问公有成员** vs **通过 get/set 接口**。
- 真实项目里数据成员通常设 `private`、只暴露 get/set（封装）；本例为了演示方便用了 public。

## 四、顺带：vector 与迭代器

同一份练习里还出现了 `vector` 的基础用法：

```cpp
#include <vector>

int a[4] = {2, 7, 11, 15};
vector<int> c(a, a + 4);            // 用数组区间构造
c.push_back(1);                     // 尾部追加
for (size_t i = 0; i < c.size(); i++)
    cout << c[i] << endl;

vector<int> result = /* 某个函数返回 */;
for (vector<int>::iterator it = result.begin(); it != result.end(); it++)
    cout << *it << " ";             // 迭代器解引用
```

- `vector<int> c(a, a + 4)` 是**左闭右开**区间（含 `a`，不含 `a+4`）。
- `size()` 返回 `size_t`（无符号）——和 `int` 比较会有"有符号/无符号"告警，习惯上循环变量也用 `size_t`。
- C++11 起可简化为范围 for：`for (int v : c)`，迭代器也能写 `auto it = result.begin()`。
