# C/C++ 中的传值调用 / 传址调用 / 引用调用
说明：传值调用、传址调用在 C/C++ 均合法；引用调用仅 C++ 支持。

## 一、传值调用（值传递）
```c
#include<stdio.h>
void swap(int x, int y)
{
    int tmp = x;
    x = y;
    y = tmp;
}
int main(void)
{
    int a = 1, b = 2;
    printf("a=%d, b=%d\n", a, b);
    swap(a, b);
    printf("a=%d, b=%d\n", a, b);
    return 0;
}
```

**输出：**
```
a=1, b=2
a=1, b=2
```

**原理：**
实参 a, b 的值拷贝给形参 x, y  
swap 内交换的是副本，与原变量无关  
函数结束后形参销毁，原变量不受影响

## 二、传址调用（指针传递）
```c
#include<stdio.h>
void swap(int *x, int *y)
{
    int tmp = *x;
    *x = *y;
    *y = tmp;
}
int main(void)
{
    int a = 1, b = 2;
    printf("a=%d, b=%d\n", a, b);
    swap(&a, &b);
    printf("a=%d, b=%d\n", a, b);
    return 0;
}
```

**输出：**
```
a=1, b=2
a=2, b=1
```

**原理：**
传递的是变量地址（指针），仍为值拷贝  
通过地址直接操作原变量内存  
形参销毁不影响原变量，成功交换

## 三、引用调用（C++ 独有）
```cpp
#include<stdio.h>
void swap(int &x, int &y)
{
    int tmp = x;
    x = y;
    y = tmp;
}
int main(void)
{
    int a = 1, b = 2;
    printf("a=%d, b=%d\n", a, b);
    swap(a, b);
    printf("a=%d, b=%d\n", a, b);
    return 0;
}
```

**输出：**
```
a=1, b=2
a=2, b=1
```

**原理：**
`&x` 是引用，即原变量的别名  
无拷贝，直接操作 a, b 本身  
C 语言无引用，必须用 g++ 编译

## 四、使用建议
- 基本类型（int、float 等）：优先传值，简单高效
- 结构体 / 类对象：建议 `const &` 传递，避免拷贝开销
- 不要为了“效率”把 `void f(int)` 改成 `void f(const int&)`，反而降低可读性
