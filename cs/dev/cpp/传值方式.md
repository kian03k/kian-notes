# C/C++ 中的传值调用 / 传址调用 / 引用调用
说明：传值调用、传址调用在 C/C++ 均合法；引用调用仅 C++ 支持。

## 一、传值调用（值传递）
```c
#include<stdio.h>
void swap(int x, int y)
{
    int tmp = x;
    x = y;
    y = tmp;
}
int main(void)
{
    int a = 1, b = 2;
    printf("a=%d, b=%d\n", a, b);
    swap(a, b);
    printf("a=%d, b=%d\n", a, b);
    return 0;
}
```

**输出：**
```
a=1, b=2
a=1, b=2
```

**原理：**
实参 a, b 的值拷贝给形参 x, y  
swap 内交换的是副本，与原变量无关  
函数结束后形参销毁，原变量不受影响

## 二、传址调用（指针传递）
```c
#include<stdio.h>
void swap(int *x, int *y)
{
    int tmp = *x;
    *x = *y;
    *y = tmp;
}
int main(void)
{
    int a = 1, b = 2;
    printf("a=%d, b=%d\n", a, b);
    swap(&a, &b);
    printf("a=%d, b=%d\n", a, b);
    return 0;
}
```

**输出：**
```
a=1, b=2
a=2, b=1
```

**原理：**
传递的是变量地址（指针），仍为值拷贝  
通过地址直接操作原变量内存  
形参销毁不影响原变量，成功交换

## 三、引用调用（C++ 独有）
```cpp
#include<stdio.h>
void swap(int &x, int &y)
{
    int tmp = x;
    x = y;
    y = tmp;
}
int main(void)
{
    int a = 1, b = 2;
    printf("a=%d, b=%d\n", a, b);
    swap(a, b);
    printf("a=%d, b=%d\n", a, b);
    return 0;
}
```

**输出：**
```
a=1, b=2
a=2, b=1
```

**原理：**
`&x` 是引用，即原变量的别名  
无拷贝，直接操作 a, b 本身  
C 语言无引用，必须用 g++ 编译

## 四、补充示例

### 4.1 指针与地址（`int*` / `int**`）
> 配合 §二「传址调用」——传址的前提是能拿到地址，这是最直观的地址演示。

```cpp
#include <stdio.h>

int main() {
    int a = 5;
    int *p = &a;             // p 保存 a 的地址
    int **q = &p;            // q 保存 p 的地址（二级指针）
    printf("p = %d\n", p);
    printf("%d", q);
}
```
- `&a` 取地址，`*p` 解引用；`int**` 是"指向指针的指针"，二级指针常见于"要在函数里改指针本身"的场景。
- ⚠️ **打印地址应该用 `%p`**（并转 `void*`），原代码用 `%d` 属未定义行为 —— 64 位下指针 8 字节、`int` 只有 4 字节，会被截断。

### 4.2 引用形参直接改实参
> §三「引用调用」的极简版：不靠返回值，直接用引用把结果写回实参。

```cpp
#include <stdio.h>

bool del(int &a) {           // a 是实参的别名
    a = 7;
    return true;
}

int main() {
    int a;                   // ⚠️ 未初始化
    del(a);
    printf("%d", a);         // 输出 7 —— del 通过引用改掉了它
}
```
- 这就是「引用作输出参数」的典型写法；换成 C 就得写 `bool del(int *a)` 再 `del(&a)`。
- ⚠️ **`int a;` 未初始化**是隐患：本例里 `del` 立刻赋了值才没暴露，一旦漏调就会打印随机值。养成 `int a = 0;` 的习惯。

## 五、使用建议
- 基本类型（int、float 等）：优先传值，简单高效
- 结构体 / 类对象：建议 `const &` 传递，避免拷贝开销
- 不要为了“效率”把 `void f(int)` 改成 `void f(const int&)`，反而降低可读性
