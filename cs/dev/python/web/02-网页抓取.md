# 网页抓取三件套（requests / Selenium / 拼 URL）

> **适用场景**：抓静态页正文、处理 JS 渲染或需要点验证的页面、下载地址要自己拼。
> **合规前提**：只抓公开数据、控制频率、遵守 robots.txt 与版权规定，仅用于个人学习。

## 1. 方案 ①：静态页 —— requests + BeautifulSoup

```python
resp = requests.get(url, headers={"User-Agent": "Mozilla/5.0 ..."}, timeout=15)
soup = BeautifulSoup(resp.text, "html.parser")
node = soup.select_one("div.article")        # CSS 选择器定位
for tag in node.find_all(["p", "a", "span", "div"]):
    tag.extract()                            # 剥掉会混入噪音的内联标签
text = node.get_text(strip=True)
```

三个要点：

- **编码**：中文页常是 `gbk`，`r.encoding = "gbk"` 或用 `r.apparent_encoding` 自动猜；
- **剥标签**：`extract()` 直接删节点，比正则干净；
- **翻页**：URL 规律时用模板 `f".../post_{n}.html"` 循环即可。

## 2. 方案 ②：动态页 / 过验证 —— Selenium

页面内容靠 JS 渲染，或下载链接需要点过弹窗/验证时，开真实浏览器：

```python
from selenium import webdriver
from selenium.webdriver.common.by import By

driver = webdriver.Edge()            # 或 Chrome，需对应 driver
driver.get(url)
time.sleep(3)                         # 粗暴等渲染（正式可用 WebDriverWait）
src = driver.find_element(By.TAG_NAME, "video").get_attribute("src")
```

> 等待渲染的稳妥写法：`WebDriverWait(driver, 10).until(EC.presence_of_element_located((By.ID, "...")))`。
> 抓完记得 `driver.quit()`，否则后台残留浏览器进程。

## 3. 方案 ③：构造编码后的下载链接

有些站点把文件名 `quote` 编码后拼进路径，下载地址要自己拼：

```python
from urllib import parse

url = base + parse.quote(filename) + suffix
```

## 4. 陷阱清单

| 坑 | 后果 | 对策 |
|---|---|---|
| 不带 `User-Agent` | 被直接拒绝 / 返回空页 | 带浏览器 UA |
| 不设 `timeout` | 挂死不动 | `timeout=15` 必写 |
| 编码没处理 | 中文全乱码 | 显式 `encoding` 或 `apparent_encoding` |
| 抓得太快 | 被限流 / 封 IP | `time.sleep(delay)` 控制频率 |
| 依赖登录态 | 换台机器就 401 | 复用 cookie / 用 Selenium 保持会话 |
| 用正则解析 HTML | 结构一变全崩 | 用 CSS 选择器 / XPath |
