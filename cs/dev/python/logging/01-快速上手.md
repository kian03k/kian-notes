# 01 快速上手：单文件脚本接入日志

> 适用：单个脚本、临时工具、学习 demo。多模块项目直接看 [[02-标准框架]]。

## 1. 为什么不用 print

| print 的问题 | 后果 |
| --- | --- |
| 没有时间戳 | 无法还原问题发生顺序 |
| 没有级别 | "支付失败"和"用户登录"看起来一样重要 |
| 无法关闭 | 上线后要删掉所有 print，或日志刷屏 |

logging 一次配置即可：自动加时间、按级别过滤、可同时输出控制台和文件。

## 2. 五个日志级别

| 级别 | 用法 | 例子 |
| --- | --- | --- |
| `DEBUG` | 调试细节，生产环境通常关闭 | "正在查询数据库第 3 行" |
| `INFO` | 正常流程记录 | "用户登录成功" |
| `WARNING` | 有异常但可继续 | "用户密码输入错误" |
| `ERROR` | 出错、功能失败 | "支付失败、数据库连不上" |
| `CRITICAL` | 系统级严重故障 | "内存耗尽，系统即将崩溃" |

## 3. 三步接入（复制即用）

```python
import logging

logging.basicConfig(
    level=logging.INFO,                                 # 只记录 INFO 及以上
    format='%(asctime)s - %(levelname)s - %(message)s', # 时间 - 级别 - 正文
    datefmt='%Y-%m-%d %H:%M:%S'                         # 去掉毫秒，便于解析
)

logging.info("开始执行分值合并操作")
logging.warning("用户输入的密码错了")
logging.error("支付系统连接失败了！")
```

输出：

```
2025-04-05 10:30:00 - INFO - 开始执行分值合并操作
2025-04-05 10:30:01 - WARNING - 用户输入的密码错了
2025-04-05 10:30:02 - ERROR - 支付系统连接失败了！
```

> `basicConfig` 全程序只调用一次，放在入口最前面。

## 4. format 占位符速查

| 占位符 | 含义 | 示例值 |
| --- | --- | --- |
| `%(asctime)s` | 时间戳，默认 `YYYY-MM-DD HH:MM:SS,mmm` | `2025-04-05 10:30:00,123` |
| `%(levelname)s` | 级别名 | `INFO` |
| `%(message)s` | 日志正文，即调用时传入的字符串 | `开始执行分值合并操作` |
| `%(name)s` | logger 名（一般即模块路径） | `utils.score_merge` |
| `%(filename)s` | 源文件名 | `score_merge.py` |
| `%(lineno)d` | 调用所在行号 | `42` |
| `%(funcName)s` | 调用所在函数名 | `merge_scores` |
| `%(module)s` | 模块名 | `score_merge` |
| `%(pathname)s` | 源文件完整路径 | `D:\app\utils\score_merge.py` |
| `%(thread)d` | 线程 ID | `12345` |
| `%(process)d` | 进程 ID | `9876` |

## 5. 场景推荐格式

| 场景 | 推荐写法 |
| --- | --- |
| 通用生产环境 | `'%(asctime)s - %(name)s - %(levelname)s - %(message)s'` |
| 调试阶段快速定位 | 追加 `%(filename)s:%(lineno)d` |
| 多模块项目 | 必带 `%(name)s`，否则分不清来源 |
| 日志要给 grep/ELK 解析 | 配 `datefmt='%Y-%m-%d %H:%M:%S'` 去掉毫秒 |

## 6. 一步到位：控制台 + 文件同时输出

```python
logger = logging.getLogger(__name__)
logging.basicConfig(
    level=logging.INFO,
    format='%(asctime)s - %(levelname)s - %(message)s',
    handlers=[
        logging.FileHandler('app.log', mode='a', encoding='utf-8'),  # 'a' 追加，不覆盖历史
        logging.StreamHandler()
    ]
)
```
