## 30 秒核心概念

| 概念 | 作用 |
| --- | --- |
| Logger | 记录器。业务模块统一 `logger = logging.getLogger(__name__)`，每模块一个 |
| Handler | 决定日志**去哪**：`StreamHandler` 控制台、`FileHandler` 文件 |
| Formatter | 决定日志**长什么样**：时间、级别、来源、正文 |
| Level | 过滤门槛：`DEBUG < INFO < WARNING < ERROR < CRITICAL` |
| root logger | 全局默认记录器，`logging.info()` 不带名字时用的就是它 |
| 传播机制 | 模块 logger 默认不配 handler，日志沿层级传给 root 的 handler 统一输出 |

## 一条铁律

配置只在入口做一次，业务模块只写固定两行：

```python
import logging
logger = logging.getLogger(__name__)
```

选型：单脚本用 `basicConfig`（01），项目用 `setup_logging()`（02），复杂需求在其上叠加（03/04）。
