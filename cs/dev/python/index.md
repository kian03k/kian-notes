# Python · 索引

> 八个顶层分类，按「处理的是什么对象」划分：
> - `guide/` — 语言本身怎么写（按序读）
> - `data/` — 打开某种内容 → 解析 → 改写 → 出图
> - `files/` — 对文件本身动手（改名 / 去重 / 监听 / 路径操作）
> - `web/` — 跟浏览器和 HTTP 打交道
> - `gui/` — 做桌面窗口：控件、布局、进度反馈
> - `cache/` — 算过的结果留下来复用，别重复算
> - `quality/` — 出错时看得见、运行时扛得住
> - `env/` — 从装环境到打包交出去
