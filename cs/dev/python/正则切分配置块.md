# 正则切分配置块

## 场景

解析设备配置导出文本，需要把每个 ACL 块完整切出，供后续按块提取规则、比对差异。

配置的特点：

- 块与块之间可能以 `#` 分隔，也可能直接紧跟下一条 `acl` 命令，没有统一分隔符；
- 存在 IPv4 / IPv6 两种写法；
- 标识可能是数字编号，也可能是名称。

因此不能按行号或空行切分，必须用"块首 + 前瞻"的方式。

## 模式

```python
import re

TAIL = r"[\s\S]*?(?=\n(?:acl\s+(?:ipv6\s+)?(?:number|name)\s+\S+|\s*#)|\Z)"

num_pattern  = re.compile(r"acl\s+(?:ipv6\s+)?number\s+(\d+)\b" + TAIL, re.I)
name_pattern = re.compile(r"acl\s+(?:ipv6\s+)?name\s+(\S+)\b" + TAIL, re.I)
```

两个模式只在块首的 `number\s+(\d+)` 与 `name\s+(\S+)` 上不同，尾部逻辑共用。

## 拆解

| 片段 | 作用 |
|---|---|
| `acl\s+(?:ipv6\s+)?` | 块首；`ipv6` 为可选非捕获组，同时兼容 IPv4 ACL |
| `number\s+(\d+)` / `name\s+(\S+)` | 捕获编号或名称到 `group(1)` |
| `\b` | 防止把 `number 6005x` 这类内容误判为块首 |
| `[\s\S]*?` | 非贪婪匹配块体，命中结束条件立即停止 |
| `(?=\n(?:acl\s+...\|\s*#)\|\Z)` | 前瞻断言：下一行是新的 `acl`、或是 `#`、或已到文本末尾 |

四个设计要点：

1. **用 `[\s\S]` 而非 `.`。** `[\s\S]` 匹配任意字符且不依赖 `re.S`，即使后续有人去掉 `DOTALL` 也不会静默失效。
2. **用前瞻而非捕获收尾。** `(?=...)` 只判断不消耗，因此 `group(0)` 中不含 `#` 和下一块的块首，切割结果天然干净。
3. **`\n` 锚定行首。** `\n\s*#` 要求 `#` 出现在行首（允许前导空白），避免把 `description` 里的 `#` 当作块结束。
4. **`\Z` 兜底。** 最后一块后面没有分隔符，靠 `\Z` 在文本末尾终止。

## 验证

以下输入包含三种边界：以 `#` 结尾、无 `#` 但与下一块相邻、文件末尾。

```python
content = """acl ipv6 number 6005
 description For_SA_Service
 rule 5 permit ipv6 source user-group nat444-group-10
 rule 10 permit ipv6 source user-group nat444-group-11
#
acl ipv6 number 6006
 rule 5 permit ipv6 source user-group other-group
#
acl ipv6 name MyACL
 rule 10 permit ipv6 source user-group admin
acl ipv6 number 6007
 rule 5 permit ipv6 source user-group last-group
"""

for m in num_pattern.finditer(content):
    print(m.group(1), len(m.group(0).splitlines()), "#" in m.group(0))
for m in name_pattern.finditer(content):
    print(m.group(1), len(m.group(0).splitlines()), "#" in m.group(0))
```

实测输出（Python 3.13）：

```
6005 4 False
6006 2 False
6007 2 False
MyACL 2 False
```

四个块全部切出，均不含 `#`，也未被下一块的块首污染。

## 局限

- 若某条规则行的行首恰好是 `acl ` 开头（如注释），会被误判为块首。设备配置导出中少见，需要时可在块首断言前再加 `^` 锚定并开启 `re.M`。
- `\s*` 包含换行，`\n\n#` 也能命中前瞻，但前瞻不消耗字符，不影响切割结果。

## 复用

同一结构可直接套用到 `firewall`、`policy`、`interface` 等以命令开头、以 `#` 或下一条同类命令分隔的配置块，只需替换块首的匹配式，`TAIL` 保持不变。
