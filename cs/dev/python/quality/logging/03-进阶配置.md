# 03 进阶配置：轮转与精细控制

> 前提：已按 [[02-标准框架]] 用 `setup_logging()` 统一配置。本篇所有改动只动配置文件，业务模块零修改。

## 1. 日志文件轮转

单文件日志会无限增长，生产环境必配轮转。

### 按大小轮转（推荐）

```python
from logging.handlers import RotatingFileHandler

file_handler = RotatingFileHandler(
    "./log.log",
    maxBytes=10 * 1024 * 1024,   # 单文件上限 10MB
    backupCount=5,               # 保留 5 个历史（log.log.1 ~ log.log.5）
    encoding="utf-8",
)
```

### 按时间轮转

```python
from logging.handlers import TimedRotatingFileHandler

file_handler = TimedRotatingFileHandler(
    "./log.log",
    when="midnight",             # 每天零点切割；也支持 'H'（每小时）、'W0'-'W6'（每周）
    backupCount=30,              # 保留 30 份
    encoding="utf-8",
)
```

> 只需替换 setup_logging() 里的 `file_handler`，所有模块自动受益。

## 2. 控制台与文件分开控级

标准框架的默认分工：**控制台 DEBUG 全量、文件 INFO 以上**。调整方法就是改各 handler 的 `setLevel`：

| 需求 | 改法 |
| --- | --- |
| 上线后控制台安静些 | `stream_handler.setLevel(logging.WARNING)` |
| 排查期文件也要 DEBUG | `file_handler.setLevel(logging.DEBUG)` |
| 调整总开关 | 入口改 `setup_logging(level=logging.INFO)` |

## 3. 模块级精细控制

利用 logger 树（`root → Src → Src.utils.data_processor`），按名字前缀对整个子树调级：

```python
# 在 setup_logging() 之后、或入口 main.py 中
logging.getLogger("Src.api").setLevel(logging.DEBUG)      # api 子树全量 DEBUG
logging.getLogger("Src.utils").setLevel(logging.INFO)     # utils 只记 INFO 以上
```

压制第三方库刷屏（urllib3、matplotlib 等常用 DEBUG 狂刷）：

```python
logging.getLogger("urllib3").setLevel(logging.WARNING)
logging.getLogger("matplotlib").setLevel(logging.WARNING)
```

## 4. dictConfig：配置中心化（微服务 / 多环境）

配置与代码分离，不同环境换不同配置：

```python
import logging.config

LOGGING_CONFIG = {
    "version": 1,
    "disable_existing_loggers": False,   # 必须为 False，否则已创建的 logger 会被禁用
    "formatters": {
        "standard": {"format": "%(asctime)s-%(levelname)s-%(filename)s:%(lineno)d - %(message)s"},
    },
    "handlers": {
        "console": {"class": "logging.StreamHandler", "level": "DEBUG", "formatter": "standard"},
        "file": {
            "class": "logging.handlers.RotatingFileHandler",
            "level": "INFO", "formatter": "standard",
            "filename": "log.log", "maxBytes": 10485760, "backupCount": 5, "encoding": "utf-8",
        },
    },
    "root": {"level": "DEBUG", "handlers": ["console", "file"]},
}

logging.config.dictConfig(LOGGING_CONFIG)
```

> 也可写成 YAML，用 `yaml.safe_load()` 读入后同样交给 `dictConfig()`。

## 5. 输出到远程（ELK 等集中采集）

```python
from logging.handlers import SocketHandler   # 或 HTTPHandler

remote_handler = SocketHandler("log-collector.example.com", 5959)
logging.getLogger().addHandler(remote_handler)
```

> 远程 handler 建议只在服务端环境启用；本机开发保持 02 的最小配置即可。
