# 正则速查与替换

> **适用场景**：批量替换敏感词、从混杂文本里捞数字/字段、按多个分隔符切分、文本清洗后统计词频。
> **配套**：要取出**子串片段**（捕获组）看 [[03-正则匹配对象]]；要切分结构化配置块看 [[04-正则切分配置块]]。

## 1. 方案：批量替换（含动态词表）

```python
import re

# 多个词用 | 连接
text = "      黄色暴力真棒    黄色"
re.sub(r"黄色|暴力", "***", text)              # 全部替换
re.sub(r"黄色|暴力", "***", text, count=1)     # 只替换第 1 个
re.sub(r"|".join(["黄色", "暴力"]), "***", text)  # 词表动态拼接
```

> 词表来自文件/配置时，**每个词都要 `re.escape()`**，否则 `.`、`*`、`(` 这类元字符会改变含义甚至报错。

## 2. 五个常用函数

| 函数 | 作用 | 返回 |
|---|---|---|
| `re.findall(p, s)` | 找所有匹配 | 列表（有捕获组时只返回组内容） |
| `re.match(p, s)` | 从**开头**匹配 | `Match` 或 `None` |
| `re.search(p, s)` | 找**第一个**匹配 | `Match` 或 `None` |
| `re.split(p, s)` | 按模式切分 | 列表 |
| `re.subn(p, r, s)` | 替换并计数 | `(新串, 替换次数)` |

```python
re.findall(r"\d+", "a12b3")           # ['12', '3']
re.match(r"^he", "hello")             # 从头匹配，返回对象或 None
re.search(r"\d+", "a12")              # 找第一个
re.split(r"[,;]", "a,b;c")            # ['a','b','c']
re.subn(r"语文", "", "语文课真好")      # ('课真好', 1)
re.compile(r"^he.*(\d+).*demo$", re.I)  # 预编译（循环里复用更快）
```

## 3. 元字符速查

| 符号 | 含义 | 符号 | 含义 |
|---|---|---|---|
| `.` | 任意字符 | `*` | 0 次或多次 |
| `\d` | 数字 | `+` | 1 次或多次 |
| `\w` | 字母数字下划线 | `?` | 0 或 1 次 |
| `\s` | 空白 | `{n,m}` | n~m 次 |
| `^` `$` | 行首 / 行尾 | `[]` | 字符集 |
| `()` | 分组捕获 | `\|` | 或 |

## 4. 方案：文本清洗 + 词频统计

```python
s = "who have an apple apple is free"
words = re.sub(r"[_.!,;:，。？、]", "", s).split()
freq = {}
for w in words:
    freq[w] = freq.get(w, 0) + 1
# {'who':1,'have':1,'an':1,'apple':2,'is':1,'free':1}
```

> 更省事的等价写法（Python 3.7+ 保序）：用 `collections.Counter(words).most_common()`。

## 5. 陷阱清单

| 坑 | 后果 | 对策 |
|---|---|---|
| 词表直接 `"\|".join(words)` | 含 `.` `()` 的词误匹配/报错 | `re.escape(w)` 包一层 |
| 用 `re.match` 找任意位置 | 只在开头找，中间命中返回 None | 找任意位置用 `re.search` |
| 循环里反复 `re.sub(r"固定模式", ...)` | 每次重新编译 | 先 `re.compile` 再 `.sub()` |
| 贪婪 `.*` 跨行吞掉整段 | 提取结果过长 | 用 `.*?` 非贪婪，或加 `re.S` 控制 |
| 拿 `Match` 直接调 `.group()` | `None` 上取属性 → `AttributeError` | 先 `if match:` 判空 |
