# 字符串清理与切分

> **适用场景**：按行读文件后去掉行尾换行、清洗日志字段两侧空白、去掉固定的前后缀、按分隔符拆字段。
> **一句话**：`rstrip()` 无参去所有尾部空白，`rstrip('\n')` 只去换行——行内空格有意义时用后者。

## 1. 去空白：四个方法

| 写法 | 去除范围 | 适用场景 |
|---|---|---|
| `.rstrip('\n')` | 仅末尾换行符 | 行内空格、制表符有意义，需要保留时 |
| `.rstrip()` | 所有尾部空白（`\n` `\r` `\t` 空格） | 通用清理，最常用且安全 |
| `.strip()` | 头尾都去 | 用户输入、日志字段两侧脏 |
| `.lstrip()` | 只去头部 | 少见，对齐修复时用 |

```python
# 按行读文件：最精确的写法
result = line[description_start:].rstrip('\n')

# 通用清理：尾部空格/制表符一并去掉
result = line[description_start:].rstrip()
```

> `rstrip()` 不带参数时默认去除所有尾部空白字符，非常常用且安全。
> 但它**也会吃掉行尾有意义的空格**（固定宽度文本、右对齐的数字列），这种场景只能用 `rstrip('\n')`。

## 2. 方案：去固定前后缀（Python 3.9+）

```python
"unsure_audio.mp3".removeprefix("unsure_")   # 'audio.mp3'
"report_final.md".removesuffix("_final.md")  # 'report'
```

老版本兼容写法：`s[len(prefix):] if s.startswith(prefix) else s`。

> 别用 `s.replace(prefix, "", 1)` 代替 —— 前缀不在开头时 `replace` 会误删中间出现的那一处。

## 3. 方案：按分隔符切分

```python
"a,b,c".split(",")          # ['a', 'b', 'c']
"a,b,c".split(",", 1)       # ['a', 'b,c']  只切第一个
"a/b/c".rsplit("/", 1)      # ['a/b', 'c']  从右往左切一个（取文件名/扩展名）
"a  b   c".split()          # ['a', 'b', 'c']  无参按任意空白切并丢弃空串
```

> `split()` 无参和 `split(" ")` 完全不同：前者把连续空格当一个分隔符且丢弃空串，后者会产生一堆 `''`。

## 4. 方案：一次做完规范化

```python
def clean(s: str) -> str:
    return s.strip().replace("\u3000", "").replace("\xa0", "").lower()
```

中文文本里常见的"看不见的空白"：

| 字符 | 名称 | 来源 | `strip()` 能去掉吗 |
|---|---|---|---|
| `\u3000` | 全角空格 | 中文排版、复制粘贴 | 能 |
| `\xa0` | 不间断空格 | 从网页复制的文本 | 能 |
| `\ufeff` | BOM | 带 BOM 的 UTF-8 文件 | **不能**，需显式 replace 或读文件时用 `utf-8-sig` |

## 5. 陷阱清单

| 坑 | 后果 | 对策 |
|---|---|---|
| `strip()` 去掉有意义的空格 | 固定宽度/右对齐数据错位 | 改用 `rstrip('\n')` |
| 用 `replace` 去前缀 | 中间同名字符串被误删 | 用 `removeprefix` |
| `split(" ")` 处理多空格 | 结果里一堆空串 | 用无参 `split()` |
| 用 `if s == " "` 判空行 | 制表符/多空格的行漏判 | 用 `if not s.strip()` |
| BOM 导致第一行匹配不上 | 看着一样的表头匹配失败 | 读文件用 `encoding="utf-8-sig"` |
