## 1. 变量与类型

```python
x = 100          # int
y = 123.456      # float
s = "abc"        # str
b = True         # bool
n = None         # 空值

type(x)          # <class 'int'>
int("18"), float("1.5"), str(99), bool(0)   # 类型转换
```

**运算符**

| 运算 | 符号 | 例 |
| --- | --- | --- |
| 整除 | `//` | `10 // 3 == 3` |
| 取余 | `%` | `5 % 8 == 5` |
| 幂 | `**` | `2 ** 3 == 8` |
| 字符串重复 | `*` | `"-" * 50` |
| 拼接 | `+` | `"a" + "b"` |

> 逻辑运算符是 `and` / `or` / `not`（**不是** `&&` / `||` / `!`）。

**格式化输出（三种写法）**

```python
name, num = "kian", 2025060018
print("名字:%s 学号:%d" % (name, num))        # % 风格
print(f"名字:{name} 学号:{num}")               # f-string（推荐）
print("名字:{0} 学号:{1}".format(name, num))   # format
print("%.2f" % (1/3))                         # 保留 2 位：0.33
```

## 2. 流程控制

```python
# if / elif / else —— 靠缩进划分代码块，没有大括号
if age >= 0 and age <= 120:
    print("年龄正确")
elif age > 120:
    print("成精了")
else:
    print("非法")

# while
i, total = 0, 0
while i <= 100:
    total += i
    i += 1

# for + range
for i in range(3):        # 0,1,2
    print(i)

# for-else：循环"正常走完"（没被 break）才执行 else —— 判断素数的经典写法
for i in range(2, 1001):
    for j in range(2, i):
        if i % j == 0:
            break
    else:
        print(i, end=" ")     # 只有质数会走到这
```

`break` 跳出整个循环，`continue` 跳过本次进入下一次。

## 3. 数据结构

### 列表 list（可变、有序）

```python
a = [3, 1, 2]
a.append(4)          # 尾部追加
a.insert(1, 9)       # 指定位置插入
a.remove(1)          # 按值删（删第一个匹配）
a.pop()              # 弹出尾部；pop(2) 弹指定下标
del a[0]             # 按下标删
a.sort()             # 原地升序；sort(reverse=True) 降序
b = sorted(a)        # 返回新列表，不改原列表
a.index(2), a.count(2)
a.extend([5, 6])     # 合并另一个列表
```

### 元组 tuple（不可变）

```python
t = ("zhangsan", 18, 1.75)
t2 = ()              # 空元组
t3 = (50,)           # ⚠️ 单元素元组必须有逗号
t[0], len(t), t.count("zhangsan")
name, age = ("kian", 18)   # 解包
```

### 字典 dict（键值对）

```python
d = {"id": 201, "name": "kian", "math": 89}
d["school"] = "henu"        # 增/改
del d["school"]             # 删
d.get("age", 0)             # 安全取值（键不存在返回默认）
d.keys(), d.values(), d.items()

for k, v in d.items():      # 遍历
    print(k, v)

# 两个列表 zip 成字典
dict(zip(["name", "age"], ["Dong", 38]))   # {'name': 'Dong', 'age': 38}
```

### 集合 set（去重、无序）

```python
s = {1, 2, 2, 3}     # {1, 2, 3}
s.add(4); s.discard(1)   # 交并差：s & t, s | t, s - t
```

### 切片（str / list / tuple 通用）

```python
a = "abcdefg"
a[2:5]      # 'cde'   取索引 2~4
a[2:]       # 'cdefg'
a[:5]       # 'abcde'
a[::2]      # 'aceg'  步长 2
a[::-1]     # 'gfedcba'  逆序（面试常问）
a[-1]       # 'g'  倒数第一个

# ⚠️ 切片返回新对象，但元素仍是原引用（浅拷贝，见 02-函数进阶）
```

## 4. 函数基础

```python
def add(a, b=0, *args, **kwargs):
    """a 位置参数；b 默认参数；*args 收集多余位置参数；**kwargs 收集关键字参数"""
    return a + b

add(1, 2)
add(1)
add(1, 2, 3, 4)              # args=(3,4)
add(1, 2, x=9, y=8)          # kwargs={'x':9,'y':8}
```

- 函数内改**全局不可变变量**要 `global x`；改**外层函数的变量**用 `nonlocal x`（闭包，见 02）。
- `if __name__ == "__main__":` —— 模块被直接运行时才执行的入口，被 import 时不执行。

## 5. 推导式（Python 特色，优先用）

```python
[x * x for x in range(5)]                  # [0,1,4,9,16]
[x for x in a if x % 2 == 0]               # 带过滤
{x: x ** 2 for x in range(3)}              # 字典推导
{x for x in "aabbcc"}                      # 集合推导 -> {'a','b','c'}
[[row * col for col in range(3)] for row in range(3)]   # 嵌套
```

## 7. 文件与异常（基础）

```python
# with 自动关文件
with open("data.txt", "r", encoding="utf-8") as f:
    text = f.read()          # read() 全读 / readline() 一行 / readlines() 全部行

with open("out.txt", "w", encoding="utf-8") as f:
    f.write("hello")

# 异常
try:
    n = int(input())
    r = 10 / n
except ValueError as e:      # 类型转换失败
    print("不是数字", e)
except ZeroDivisionError:
    print("不能除以零")
except Exception as e:       # 兜底
    print("出错了", e)
else:
    print("没异常才走这里")
finally:
    print("无论如何都执行（常用在关连接）")
```

## 9. ⚠️ 踩坑清单

| 坑 | 现象 | 正解 |
| --- | --- | --- |
| `round()` 的浮点误差 | `round(2.675, 2) == 2.67`（不是 2.68） | 用 `Decimal`（见下） |
| 浮点相等 | `4 - 3.7 == 0.3` → `False` | 用 `Decimal` 或 `abs(a-b) < 1e-9` |
| 边遍历边删列表 | 越界 / 漏删 | 倒序删 `for i in ls[::-1]`，或推导式重建 |
| 单元素元组 | `(50)` 是 int 不是 tuple | 写成 `(50,)` |
| 可变默认参数 | `def f(x=[])` 会跨调用累积 | 默认用 `None`，函数内再建列表 |
| `list.copy()` 是浅拷贝 | 改嵌套对象会连带 | 要独立用 `copy.deepcopy` |
| 字符串不可变 | `s[0] = 'x'` 报错 | 用新字符串拼接/切片 |
| 逻辑运算符 | 写成 `&&` `||` `!` | Python 是 `and` `or` `not` |

> **浮点精度**：涉及金额/精度时用 `Decimal`，且**必须传字符串**——`Decimal(0.1)` 已经把误差带进去了。
> ```python
> from decimal import Decimal
> Decimal("1.545").quantize(Decimal("0.01"), rounding="ROUND_HALF_UP")  # 1.55
> Decimal("4") - Decimal("3.7")   # Decimal('0.3')，精确
> ```
