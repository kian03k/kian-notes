## 1. 类与对象：最基础的用法

```python
class Person:
    def __init__(self, name, sex, age):   # 构造方法，创建对象时自动调用
        self.name = name                  # self 指"这个实例自己"
        self.sex = sex
        self.age = age

    def show(self):                       # 实例方法：第一个参数必须是 self
        print(f"姓名:{self.name} 性别:{self.sex} 年龄:{self.age}")

a = Person("孔宽", "男", 19)               # 创建实例
a.show()                                  # 姓名:孔宽 性别:男 年龄:19
```

**类属性 vs 实例属性**

```python
class Grade:
    passing = 60          # 类属性：所有实例共享，用 Grade.passing 访问
    def __init__(self, score):
        self.score = score  # 实例属性：每个对象各一份

g = Grade(45)
print(Grade.passing, g.passing)   # 60 60
```

## 2. 继承与多态

```python
class Person:
    def __init__(self, name, gender, age, number):
        self.name, self.gender, self.age, self.number = name, gender, age, number

class Student(Person):                        # Student 继承 Person
    def __init__(self, name, gender, age, number, college, major):
        super().__init__(name, gender, age, number)   # 调父类构造，省去重复
        self.college = college
        self.major = major

    def show(self):                           # 方法重写（覆盖父类同名方法）
        print(f"{self.name} 就读 {self.college} {self.major}")

class Teacher(Person):
    def __init__(self, name, gender, age, number, title):
        super().__init__(name, gender, age, number)
        self.title = title
    def show(self):
        print(f"{self.name} 职称 {self.title}")

# 多态：同一个 show()，不同对象各显各的
for p in [Student("kian", "男", 19, 201, "软件学院", "网络工程"),
          Teacher("王老师", "女", 56, 202, "教授")]:
    p.show()
```

**多继承**：`class Teacher(Person, Course)` —— 同时继承两个父类。`super()` 在复杂继承链下按 MRO（方法解析顺序）走，日常一个父类最省心。

**isinstance / issubclass**

```python
isinstance(s, Person)     # 子类实例也是父类的实例 -> True
issubclass(Student, Person)   # True
```

## 3. 三种"方法"：实例方法 / 类方法 / 静态方法

```python
import time

class Demo:
    __num = 0                          # 双下划线开头 = 私有，外部不能直接访问

    @classmethod
    def addNum(cls):                   # 类方法：参数是 cls（类本身），能读改类属性
        cls.__num += 1
    @classmethod
    def getNum(cls):
        return cls.__num

    @staticmethod
    def showTime():                    # 静态方法：既不用 self 也不用 cls，就是个"挂在类里的普通函数"
        return time.strftime("%H:%M:%S", time.localtime())

    def normal(self):                  # 实例方法：要用 self
        return "normal"
```

| 类型 | 装饰器 | 第一个参数 | 典型用途 |
| --- | --- | --- | --- |
| 实例方法 | 无 | `self` | 操作实例数据 |
| 类方法 | `@classmethod` | `cls` | 操作类级状态、替代构造器（`from_xxx()`） |
| 静态方法 | `@staticmethod` | 无 | 逻辑上属于类、但不碰实例/类数据 |

## 4. `@property`：把方法"变成属性"访问

```python
class Person:
    def __init__(self, name):
        self._name = name
        self._age = None

    @property
    def age(self):            # 取值时调用：p.age
        print("get age")
        return self._age

    @age.setter
    def age(self, age):       # 赋值时调用：p.age = 17
        print("set age")
        if age < 0:
            raise ValueError("年龄不能为负")
        self._age = age

p = Person("小李")
p.age = 17        # 触发 setter
print(p.age)      # 触发 getter -> 17
```

> 好处：对外仍是 `p.age` 这种"属性"写法，内部却能加**校验/计算/只读保护**。
> 只写 `@property` 不写 `.setter`，就得到一个**只读属性**。

**更老的写法**（了解即可）：
```python
# 用内置 property(fget, fset, fdel) 一次性绑定
value = property(_get, _set, _del)
```
现在一律用 `@property` 装饰器版本。

## 5. 魔术方法（dunder）

```python
class ListNode:
    def __init__(self, x):
        self.val = x

    def __repr__(self):        # 决定 print()/调试时的显示
        return str(self.val)

    def __len__(self):
        return len(self.val)

print([ListNode(1), ListNode(2)])   # [1, 2]  —— 靠 __repr__
```

**`__new__` vs `__init__`**（经典题）：`__new__` 真正**创建**对象并返回，`__init__` 只是**初始化**已创建的对象。

```python
class ClassTest:
    __num = 0
    @classmethod
    def addNum(cls):
        cls.__num += 1
    @classmethod
    def getNum(cls):
        return cls.__num

    def __new__(cls):                # 每次实例化都会先进这里
        ClassTest.addNum()           # 用"创建时机"做人头计数
        return super().__new__(cls)

a, b = ClassTest(), ClassTest()
print(ClassTest.getNum())            # 2
```

> 用途：单例模式（`__new__` 里缓存实例）、不可变类型子类化、控制对象创建。

## 6. 自定义异常

```python
class OutOfStock(Exception):            # 继承 Exception
    def __init__(self, value):
        self.value = value
    def __str__(self):                  # 决定 print(e) 的内容
        return f"你要买 {self.value} 个，已超过库存。"

stock = {"blue": 6, "red": 2}
try:
    color = input("颜色:")
    num = int(input("数量:"))
    if stock.get(color, 0) - num < 0:
        raise OutOfStock(num)           # 主动抛出
except OutOfStock as e:
    print(e)                            # 你要买 8 个，已超过库存。
```

> 自定义异常让"业务错误"和"程序错误"区分开，`except` 时能精准捕获。
> 继承 `Exception` 而非 `BaseException`（后者是给 `KeyboardInterrupt` 等系统级用的）。

## 7. 动手小练习（原 practice 精华）

把上面拼起来：**对象列表 + 排序 + 深拷贝**

```python
import copy

class Student:
    def __init__(self, sno, name, score):
        self.sno, self.name, self.score = sno, name, score
    def info(self):
        print(f"学号:{self.sno} 姓名:{self.name} 成绩:{self.score}")

stu_list = [Student("001", "AAA", 100), Student("002", "BBB", 89), Student("003", "CCC", 76)]

# 按成绩升序（sorted 返回新列表，不改原列表）
by_score = sorted(stu_list, key=lambda s: s.score)
by_score[0].info()               # 最低分
by_score[-1].info()              # 最高分

# 深拷贝后翻转，得到完全独立的一份
reversed_copy = copy.deepcopy(stu_list)[::-1]
```

> `sorted(key=...)` 是 OOP + 高阶函数 + lambda 的综合运用，非常 Pythonic，务必熟练。

| 概念 | 记忆点 |
| --- | --- |
| 类/实例属性 | 类属性共享、实例属性独占 |
