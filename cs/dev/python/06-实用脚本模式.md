# Python 实用脚本模式

> 从一批日常小工具里提炼的高频套路：**文件批处理 / 媒体处理 / 网页抓取**。
> 每个模式只讲"怎么做、坑在哪"。可运行的成品种脚本见工作区 `~/workspace/projects/py-toolbox/`。

## 1. 批量重命名

三种常见需求，都靠 `os.rename` / `Path.rename` + `os.path.splitext`。

**① 统一改名（前缀 + 序号）** —— 给数据集图片铺命名：

```python
import os

def rename_all(folder, prefix="img_", ext=None):
    i = 1
    for name in os.listdir(folder):
        old = os.path.join(folder, name)
        if os.path.isdir(old):
            continue
        suffix = ext or os.path.splitext(old)[1]   # 保留原扩展名，或强制统一
        os.rename(old, os.path.join(folder, f"{prefix}{i}{suffix}"))
        i += 1
```

**② 按文件大小排序后再改名** —— 让序列和体积相关（大文件排在后面）：

```python
items = sorted(
    ((os.path.join(folder, n), os.path.getsize(os.path.join(folder, n)))
     for n in os.listdir(folder)),
    key=lambda x: x[1],
)
```

**③ 跨文件夹按序套用名字** —— 两个文件夹文件一一对应（如"拍照件"的名字套到"扫描件"上）：

```python
from pathlib import Path
f1 = [f for f in Path(dir1).iterdir() if f.is_file()]
f2 = [f for f in Path(dir2).iterdir() if f.is_file()]
for src, dst in zip(f1, f2):
    dst.rename(dst.with_name(src.stem + dst.suffix))   # 只借名字，留自己的后缀
```

> ⚠️ 坑：**防撞名**。改名时若目标名已存在，`os.rename` 会直接覆盖！
> 稳妥做法是加 `while os.path.exists(new): i += 1` 循环找空位。

## 2. 重复文件检测

按内容判断重复（而不是文件名），用标准库 `filecmp`：

```python
import filecmp, os

def find_duplicates(folder):
    names = sorted(os.listdir(folder), key=lambda f: os.path.getsize(os.path.join(folder, f)))
    dups = []
    for a, b in zip(names, names[1:]):          # 先按大小排序，只比相邻
        if filecmp.cmp(os.path.join(folder, a), os.path.join(folder, b), shallow=False):
            dups.append(os.path.join(folder, b))
    return dups
```

两个关键点：
- **`shallow=False`** 才会真正逐字节比较；默认 `shallow=True` 只比 `os.stat`（大小+时间），不可靠。
- **先按大小排序**再比相邻项，体积不同的文件直接跳过，省大量 IO（真正内容相同的文件大小必然相同）。

## 3. 目录体积分析

`os.walk` 递归累加，再自己做单位换算：

```python
def dir_size(path):
    total = 0
    for parent, _dirs, files in os.walk(path):
        for name in files:
            try:
                total += os.path.getsize(os.path.join(parent, name))
            except OSError:      # 断开/权限不足的文件跳过
                continue
    return total

def human(n):
    for unit in ("B", "KB", "MB", "GB", "TB"):
        if n < 1024:
            return f"{n:.1f}{unit}"
        n /= 1024
    return f"{n:.1f}PB"
```

> 用途：磁盘清理、仓库瘦身时先跑一遍，一眼看出谁最占地方。

## 4. 目录监听自动化（watchdog）

让脚本常驻，文件夹一有新文件就自动处理（配合上面的「排序改名 + 去重」很实用）：

```python
from watchdog.observers import Observer
from watchdog.events import FileSystemEventHandler
import time

class Handler(FileSystemEventHandler):
    def on_created(self, event):
        if not event.is_directory:
            run_once(...)             # 新文件落地 -> 重跑整理逻辑

obs = Observer()
obs.schedule(Handler(), folder, recursive=True)
obs.start()
try:
    while True:
        time.sleep(1)
except KeyboardInterrupt:
    obs.stop()
obs.join()
```

> ⚠️ `watchdog` 是第三方库（`pip install watchdog`）。`on_created` 触发时文件**可能还没写完**，
> 对"边下载边产生"的场景最好加个延时或大小稳定检测再处理。

## 5. CSV 列重排与值映射

数据集预处理常见两步：**换列序** + **改标签取值**。用标准库 `csv`：

```python
import csv
with open("in.csv", newline="", encoding="utf-8") as f:
    rows = list(csv.reader(f))

for row in rows:                       # 交换前两列
    row[0], row[1] = row[1], row[0]

for row in rows:                       # 标签 1/0 -> 正面/负面
    row[1] = {"1": "正面", "0": "负面"}.get(row[1], row[1])

with open("out.csv", "w", newline="", encoding="utf-8") as f:
    csv.writer(f).writerows(rows)
```

> ⚠️ 三个坑：
> - `open(..., newline="")` 必须写，否则 Windows 下会多出空行；
> - 大文件别 `list(reader)` 全读进内存，逐行流式处理；
> - 中文 CSV 常见 `gbk`/`utf-8-sig`，读不动时换 `encoding` 试试。

## 6. 调用 FFmpeg（subprocess）

Python 本身不处理音视频，靠 `subprocess` 拼命令行调 FFmpeg / ffprobe。
**推荐用列表传参**（`["ffmpeg", "-i", path, ...]`），别用字符串拼接，免去转义地狱。

**① 音频批量转 MP3**

```python
subprocess.run([
    "ffmpeg", "-y", "-hide_banner", "-loglevel", "error",
    "-i", str(src),
    "-codec:a", "libmp3lame", "-b:a", "320k",
    str(tmp),                     # 先写临时文件 unsure_x.mp3
])
```

> 模式：**先写临时文件，成功后再 `rename` 成目标名**。这样中途中断只会留下 `unsure_` 前缀的残file，
> 不会污染正式产物；下次运行还能靠"目标已存在就跳过"避免重复转换。

**② 视频掐头去尾（无损）**

```python
total = float(subprocess.run(
    ["ffprobe", "-i", src, "-show_entries", "format=duration", "-v", "quiet", "-of", "csv=p=0"],
    stdout=subprocess.PIPE, text=True).stdout)

subprocess.run([
    "ffmpeg", "-i", src, "-ss", str(start), "-to", str(total - end),
    "-c", "copy",                 # 不重新编码：快、无损
    "-fflags", "+genpts",         # 关键：重写时间戳，防播放器时间轴错乱
    dst,
])
```

**③ 抽音频：两种策略**

| 策略 | 命令 | 特点 |
| --- | --- | --- |
| 原样复制 | `-vn -acodec copy` | 快、无损，编码随源（mp4→aac） |
| 重编码 MP3 | `-vn -q:a 0 -map a` | 通用，耗时、有损（`-q:a 0` 为最高音质） |

> 常用参数速记：`-y` 覆盖输出、`-hide_banner -loglevel error` 静音日志、
> `-b:a 320k` 码率、`-c copy` 流复制不转码。

## 7. 网页抓取三件套

**① 静态页：requests + BeautifulSoup**

```python
resp = requests.get(url, headers={"User-Agent": "Mozilla/5.0 ..."}, timeout=15)
soup = BeautifulSoup(resp.text, "html.parser")
node = soup.select_one("div.article")        # CSS 选择器定位
for tag in node.find_all(["p", "a", "span", "div"]):
    tag.extract()                            # 剥掉会混入噪音的内联标签
text = node.get_text(strip=True)
```

- **编码**：中文页常是 `gbk`，`r.encoding = "gbk"` 或用 `r.apparent_encoding` 自动猜。
- **剥标签**：`extract()` 直接删节点，比正则干净。
- **翻页**：URL 规律时用模板 `f".../post_{n}.html"` 循环即可。

**② 动态页 / 过验证：Selenium**

页面内容靠 JS 渲染，或下载链接需要点过弹窗/验证时，用 Selenium 开真实浏览器：

```python
from selenium import webdriver
from selenium.webdriver.common.by import By

driver = webdriver.Edge()            # 或 Chrome，需对应 driver
driver.get(url)
import time; time.sleep(3)           # 粗暴等渲染（正式可用 WebDriverWait）
src = driver.find_element(By.TAG_NAME, "video").get_attribute("src")
```

**③ 构造加密下载链接**

有些站点把文件名 `quote` 编码后拼进路径，下载地址要自己拼（还能顺手绕开"文件不存在"的假 404）：

```python
from urllib import parse
url = base + parse.quote(filename) + suffix
```

> ⚠️ 礼貌抓取：加 `time.sleep(delay)` 控制频率，遵守 robots.txt 与版权规定。
> 只对"公开数据 + 个人学习"用途使用。

## 小结：这些模式怎么组合

```
新文件进来 ──watchdog 监听──► 排序改名 ──► filecmp 去重 ──► 完成
                                    │
JSON/CSV 数据集 ──csv 列重排/映射──► 训练可用格式
                                    │
音视频素材 ──subprocess 调 FFmpeg──► 转换/裁剪/抽音频
                                    │
缺素材 ──requests/Selenium 抓取────► 补进数据集
```
