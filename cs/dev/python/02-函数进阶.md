## 1. 递归

函数自己调自己，**必须有终止条件**，否则爆栈。

```python
# 阶乘：递归版 vs 迭代版
def fac(n):                 # 递归
    if n == 1:              # ← 终止条件，少了它就会无限递归
        return 1
    return n * fac(n - 1)

def fac_2(n):               # 迭代（循环）
    f = 1
    for i in range(2, n + 1):
        f *= i
    return f

print(fac(5), fac_2(5))     # 120 120
```

> **什么时候用递归**：问题本身是"规模更小的同类问题"时（树遍历、汉诺塔、分治）。
> Python 默认递归深度约 1000，超了就 `RecursionError`，深层问题请改迭代。

## 2. 高阶函数：函数也是"值"

Python 里函数是**一等公民**——能赋值、能当参数、能当返回值。

```python
def FunAdd(f, x, y):     # f 是一个函数参数
    return f(x) + f(y)

def Square(x): return x ** 2
def Cube(x):   return x ** 3

print(FunAdd(Square, 3, -5))   # 9 + 25 = 34
print(FunAdd(Cube,   3, -5))   # 27 + (-125) = -98
```

**lambda** 是临时匿名函数，常配合高阶函数用，省去 def：

```python
print(FunAdd(lambda x: x ** 2, 3, -5))   # 34
print(FunAdd(lambda x: x ** 3, 3, -5))   # -98

# 实战：按字典某个字段排序
students = [{"name": "a", "math": 80}, {"name": "b", "math": 95}]
students.sort(key=lambda s: s["math"], reverse=True)
# sorted 的 key 也是同理：key 只要能被调用即可
```

## 3. 闭包

**内层函数记住了外层函数的变量**，即使外层函数已经返回。

```python
def outer(x):
    y = 10
    def inner(z):
        nonlocal x, y        # 要改外层的 x,y 才需要 nonlocal；只读可以省略
        return x + y + z
    return inner             # 返回的是"函数"，不是结果

f = outer(5)                 # x=5 被 f 记住
g = outer(50)                # 另一份独立环境 x=50
print(f(20), g(20))          # 35 80
print(f(30), g(30))          # 45 90
```

> `f` 和 `g` 各自保留了自己的 `x`——这就是**闭包**：函数 + 它捕获的环境。
> 用途：装饰器、工厂函数、延迟求值。

⚠️ **经典陷阱**：循环里创建闭包，变量是"引用"不是"值"

```python
def bad():
    fs = []
    for x in range(3):
        fs.append(lambda: x)     # 都引用同一个 x
    return fs
print([f() for f in bad()])       # [2, 2, 2]  不是 [0,1,2]！

# 修正：用默认参数把当前值"钉"住
def good():
    fs = []
    for x in range(3):
        fs.append(lambda x=x: x)  # 每次绑定当时的 x
    return fs
print([f() for f in good()])      # [0, 1, 2]
```

## 4. 装饰器

装饰器 = **接收函数、返回新函数**的高阶函数，用来在**不改原函数代码**的前提下加功能（日志、计时、鉴权、缓存）。

```python
import time

def deco(func):                    # 参数是被装饰的函数
    def inner(*args, **kwargs):    # 用 *args/**kwargs 适配任意签名
        print(">>> before")        # 前置增强
        result = func(*args, **kwargs)
        print("<<< after")         # 后置增强
        return result
    return inner                   # 返回包装后的函数

@deco                              # 等价于：say = deco(say)
def say(name):
    print("hello", name)

say("kian")
# 输出：
# >>> before
# hello kian
# <<< after
```

**多个装饰器叠加**：离函数近的先包装、后执行（洋葱模型）。

```python
def deco1(f):
    def w(*a, **k):
        print("deco1 begin"); r = f(*a, **k); print("deco1 end"); return r
    return w

def deco2(f):
    def w(*a, **k):
        print("deco2 begin"); r = f(*a, **k); print("deco2 end"); return r
    return w

@deco1
@deco2
def f2(a, b, c):
    print(a + b + c)

f2(1, 3, 5)
# deco1 begin -> deco2 begin -> 9 -> deco2 end -> deco1 end
```

**带参数的装饰器**（多包一层）：`@retry(3)`

```python
def retry(times):
    def decorator(func):
        def wrapper(*a, **k):
            for i in range(times):
                try:
                    return func(*a, **k)
                except Exception as e:
                    print(f"第{i+1}次失败: {e}")
            raise RuntimeError("重试次数用完")
        return wrapper
    return decorator
```

> ⚠️ 陷阱：装饰后 `say.__name__` 会变成 `inner`。要保留原信息就用 `functools.wraps`：
> ```python
> from functools import wraps
> def deco(func):
>     @wraps(func)          # 把原函数的 __name__/__doc__ 复制过来
>     def inner(*a, **k):
>         return func(*a, **k)
>     return inner
> ```

## 5. 深拷贝 vs 浅拷贝 ⭐

这是最容易"改一个变量结果另一个也变了"的坑。

**核心**：Python 容器里存的是**元素的引用（地址）**，不是元素本身。

```python
import copy

class ListNode:
    def __init__(self, x):
        self.val = x
    def __repr__(self):
        return str(self.val)

list1 = [ListNode(1), ListNode(2)]

list2 = list1.copy()          # 浅拷贝
list3 = list1[:]             # 浅拷贝（切片）
list4 = copy.deepcopy(list1)  # 深拷贝

list1[0].val = 5              # 改"元素内部"的值
print(list1, list2, list3, list4)
# [5, 2] [5, 2] [5, 2] [1, 2]
#            ↑ 浅拷贝跟着变了    ↑ 深拷贝不受影响

print(id(list1[0]), id(list4[0]))   # 浅拷贝同地址；深拷贝是新对象
```

| | 外层容器 | 内层元素 | 何时用 |
| --- | --- | --- | --- |
| `=` 赋值 | 同一对象 | 同一对象 | 起别名 |
| 浅拷贝 `copy()/[:]` | **新** | **共用** | 元素不可变时够用 |
| 深拷贝 `deepcopy()` | **新** | **全新** | 嵌套可变对象、要完全隔离 |

**再看一个更直观的（嵌套 list）**：

```python
stuList = ['张轩', '李岚', '王晨', ['周明', '刘峰']]
copyList = stuList.copy()

stuList[0] = '张飞'          # 改不可变元素 -> 只影响自己
print(copyList)              # ['张轩','李岚','王晨',['周明','刘峰']]

stuList[3][0] = '周颖'       # 改嵌套的"可变"元素 -> 浅拷贝受影响！
print(copyList)              # ['张轩','李岚','王晨',['周颖','刘峰']]
```

> **一句话记忆**：浅拷贝只复制"最外层的壳"，壳里的东西还是原来那批；
> 深拷贝连壳里的东西也重新造一份。

## 小结对照

| 概念 | 一句话 | 常见用途 |
| --- | --- | --- |
| 递归 | 自己调自己 + 终止条件 | 树/分治 |
| 高阶函数 | 函数当参数/返回值 | 排序 key、回调 |
| 闭包 | 内层记住外层变量 | 装饰器、工厂 |
| 装饰器 | 不改编原函数加功能 | 日志、计时、鉴权、缓存 |
| 深拷贝 | 连内部对象一起复制 | 数据隔离 |
