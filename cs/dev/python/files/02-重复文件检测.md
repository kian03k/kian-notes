# 重复文件检测（按内容）

> **适用场景**：整理下载目录、合并多个备份盘后想去重、确认"这两个是不是同一份"。
> **按内容判断，不是按文件名**——改过名的同一份文件也能查出来。

## 1. 方案：先按大小排序，再比相邻

```python
import filecmp, os

def find_duplicates(folder):
    names = sorted(os.listdir(folder), key=lambda f: os.path.getsize(os.path.join(folder, f)))
    dups = []
    for a, b in zip(names, names[1:]):          # 先按大小排序，只比相邻
        if filecmp.cmp(os.path.join(folder, a), os.path.join(folder, b), shallow=False):
            dups.append(os.path.join(folder, b))
    return dups
```

两个关键点：

- **`shallow=False`** 才会真正逐字节比较；默认 `shallow=True` 只比 `os.stat`（大小 + 修改时间），不可靠。
- **先按大小排序**再比相邻项，体积不同的文件直接跳过，省大量 IO（真正内容相同的文件大小必然相同）。

> 局限：这套只比**相邻**两个，同一大小有 3 个以上文件时可能漏。严格场景改用按 size 分桶再组内两两比。

## 2. 更稳的写法：按 (大小) 分桶

```python
import hashlib, os
from collections import defaultdict

def file_hash(path, chunk=1 << 20):
    h = hashlib.sha256()
    with open(path, "rb") as f:
        while block := f.read(chunk):
            h.update(block)
    return h.hexdigest()

def find_duplicates(folder):
    by_size = defaultdict(list)
    for name in os.listdir(folder):
        p = os.path.join(folder, name)
        if os.path.isfile(p):
            by_size[os.path.getsize(p)].append(p)

    result = {}
    for size, paths in by_size.items():
        if len(paths) < 2:
            continue                                  # 大小唯一的直接排除
        by_hash = defaultdict(list)
        for p in paths:
            by_hash[file_hash(p)].append(p)
        for h, group in by_hash.items():
            if len(group) > 1:
                result[h] = group                     # 同 hash = 同内容
    return result
```

**先比大小、再算 hash** 是标准的两级过滤：绝大多数文件在第一级就被排除，只有大小相同的才付出读盘代价。

## 3. 陷阱清单

| 坑 | 后果 | 对策 |
|---|---|---|
| 用文件名/大小当判据 | 误删不同内容、漏掉改过名的同一份 | 最终判据必须是内容 hash |
| `filecmp.cmp` 默认 `shallow=True` | 只看大小+时间，误判重复 | 显式 `shallow=False` |
| 直接对全目录算 hash | 巨慢 | 先按 size 分桶 |
| 检测完自动删 | 误删无法恢复 | 只输出列表，删除由人确认（进回收站） |
| 软链接被当文件读 | 重复统计、循环链接 | 先 `os.path.islink` 跳过 |

> 涉及个人目录时**只生成报告不动文件**，删除要单独确认。
