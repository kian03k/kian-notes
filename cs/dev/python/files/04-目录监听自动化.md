# 目录监听自动化（watchdog）

> **适用场景**：让脚本常驻，文件夹一有新文件就自动处理（配合 [[01-批量重命名]]、[[02-重复文件检测]] 很实用）。

## 1. 方案：Observer + 事件回调

```python
from watchdog.observers import Observer
from watchdog.events import FileSystemEventHandler
import time

class Handler(FileSystemEventHandler):
    def on_created(self, event):
        if not event.is_directory:
            run_once(...)             # 新文件落地 -> 重跑整理逻辑

obs = Observer()
obs.schedule(Handler(), folder, recursive=True)
obs.start()
try:
    while True:
        time.sleep(1)
except KeyboardInterrupt:
    obs.stop()
obs.join()
```

`watchdog` 是第三方库：`pip install watchdog`。

## 2. 方案：等文件写完再处理

`on_created` 触发时文件**可能还没写完**（下载中、复制中）。两种稳法：

```python
def wait_stable(path, checks=3, interval=0.5):
    """大小连续 checks 次不变才认为写完了"""
    last = -1
    stable = 0
    while stable < checks:
        time.sleep(interval)
        size = os.path.getsize(path)
        stable = stable + 1 if size == last else 0
        last = size
    return True
```

或简单粗暴延时：`on_created` 里先 `time.sleep(2)` 再处理（够用但不严谨）。

## 3. 陷阱清单

| 坑 | 后果 | 对策 |
|---|---|---|
| 收到事件立刻处理 | 读到半个文件 / 内容为空 | 大小稳定检测或延时 |
| 没排除子目录 | 目录事件也进回调 | 判断 `event.is_directory` |
| 自己写文件又触发监听 | 无限循环 | 输出目录排除在监听范围外 |
| 一次复制触发多个事件 | 同一文件被处理多次 | 按路径去重 / 节流 |
| `KeyboardInterrupt` 没清理 | 进程残留 | `finally` 里 `obs.stop(); obs.join()` |
