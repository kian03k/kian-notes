# 批量重命名（含防撞名）

> **适用场景**：给数据集图片铺命名、按体积排序后重排序号、两个文件夹的文件一一对应套名字。
> 都靠 `os.rename` / `Path.rename` + `os.path.splitext`。

## 1. 方案 ①：统一改名（前缀 + 序号）

```python
import os

def rename_all(folder, prefix="img_", ext=None):
    i = 1
    for name in os.listdir(folder):
        old = os.path.join(folder, name)
        if os.path.isdir(old):
            continue
        suffix = ext or os.path.splitext(old)[1]   # 保留原扩展名，或强制统一
        os.rename(old, os.path.join(folder, f"{prefix}{i}{suffix}"))
        i += 1
```

`ext` 传值就强制统一后缀（如全改成 `.jpg`），传 `None` 保留原后缀。

## 2. 方案 ②：按文件大小排序后再改名

让序号和体积相关（大文件排在后面）：

```python
items = sorted(
    ((os.path.join(folder, n), os.path.getsize(os.path.join(folder, n)))
     for n in os.listdir(folder)),
    key=lambda x: x[1],
)
```

排序结果 `items` 是 `[(路径, 字节数), ...]`，再按顺序套 ① 的改名逻辑即可。

## 3. 方案 ③：跨文件夹按序套用名字

两个文件夹文件一一对应（如"拍照件"的名字套到"扫描件"上）：

```python
from pathlib import Path

f1 = [f for f in Path(dir1).iterdir() if f.is_file()]
f2 = [f for f in Path(dir2).iterdir() if f.is_file()]
for src, dst in zip(f1, f2):
    dst.rename(dst.with_name(src.stem + dst.suffix))   # 只借名字，留自己的后缀
```

> `zip` 按目录遍历顺序配对，顺序不一定稳定。要求严格对应时先 `sorted()` 两边，或按文件名里的序号显式匹配。

## 4. ⚠️ 最大的坑：撞名会直接覆盖

`os.rename` 在目标名已存在时**直接覆盖，不报错、不进回收站**。

```python
def safe_rename(old, new):
    if os.path.exists(new):
        stem, suffix = os.path.splitext(new)
        i = 1
        while os.path.exists(f"{stem}_{i}{suffix}"):
            i += 1
        new = f"{stem}_{i}{suffix}"
    os.rename(old, new)
    return new
```

## 5. 陷阱清单

| 坑 | 后果 | 对策 |
|---|---|---|
| 目标名已存在 | **静默覆盖，原文件没了** | 改名前后 `os.path.exists` 检查 + 找空位 |
| `os.listdir` 顺序不确定 | 每次跑出来的编号不一样 | 先 `sorted(os.listdir(folder))` |
| 改名过程中把目录也改了 | 后续文件路径全失效 | 判断 `os.path.isdir` 跳过 |
| 改名后忘了刷新引用 | 配置文件/数据库里记的旧名字失效 | 改名和更新引用写在同一个流程里 |
| 在个人目录批量跑 | 一次错配整个目录 | 先 `print` 一遍 dry-run，确认再执行 |

> 处理个人文件（桌面、下载、文档）时，先输出改名计划让他确认，别一次跑完。
