# 目录创建与清空

> **适用场景**：脚本每次运行前要准备输出目录（不存在就建、存在就清空）、给中间产物建多级目录、保留 `.gitkeep` 时清目录。
> 核心原则：**不破坏比重建更重要**。目录结构往往是项目的骨架，一行 `rmtree` 打错就是事故。

## 1. 方案：创建目录（存在不报错）

```python
from pathlib import Path

Path("./output/data").mkdir(exist_ok=True)                    # 单层
Path("a/b/c").mkdir(parents=True, exist_ok=True)              # 多级，父目录自动建
```

| 参数 | 作用 |
|---|---|
| `exist_ok=True` | 目录已存在时不抛 `FileExistsError`（**必加**） |
| `parents=True` | 缺失的父目录一并创建，`a/b/c` 中 `a`、`b` 不存在也行 |

## 2. 方案：清空目录内容（保留目录本身）

```python
from pathlib import Path
import shutil

def empty_directory(dir_path):
    """清空目录下所有内容，保留目录本身；不存在则创建。"""
    path = Path(dir_path)

    if not path.exists():
        path.mkdir(parents=True, exist_ok=True)
        return

    if not path.is_dir():
        raise NotADirectoryError(f"{dir_path} 存在但不是目录")

    for item in list(path.iterdir()):      # 先快照，避免遍历中途变脏
        if item.is_symlink():
            item.unlink()                  # 软链接只删链接本身，不碰目标
        elif item.is_dir():
            shutil.rmtree(item)
        else:
            item.unlink()
```

| 代码 | 作用 |
|---|---|
| `path.iterdir()` | 返回**直接子项**（文件 + 目录 + 隐藏文件），不递归 |
| `list(...)` | 先取快照；直接边遍历边删，并发场景会抛 `FileNotFoundError` |
| `item.is_symlink()` | **必须在 `is_dir()` 之前判断**，见陷阱 1 |
| `shutil.rmtree(item)` | 递归删除整个子目录 |
| `item.unlink()` | 删单个文件（对目录会报错） |

## 3. 方案：保留特定文件（如 `.gitkeep`）

`iterdir()` 会返回包括点开头文件在内的**所有**条目，`.gitkeep` 会被一起删掉。要留就显式跳过：

```python
KEEP = {".gitkeep"}

for item in list(path.iterdir()):
    if item.name in KEEP:
        continue
    if item.is_symlink():
        item.unlink()
    elif item.is_dir():
        shutil.rmtree(item)
    else:
        item.unlink()
```

Git 不跟踪空目录，需要占位时：

```python
Path("my_empty_dir/.gitkeep").touch()
```

## 4. 方案：带日志的生产版

```python
import logging
import shutil
from pathlib import Path

log = logging.getLogger(__name__)

def ensure_empty_dir(dir_path, create_if_missing=True):
    """确保目录存在且为空。存在则清空（保留目录），不存在则创建。"""
    path = Path(dir_path)

    if path.exists():
        if not path.is_dir():
            raise NotADirectoryError(f"'{dir_path}' exists but is not a directory.")
        items = list(path.iterdir())
        for item in items:
            if item.is_symlink():
                item.unlink()
            elif item.is_dir():
                shutil.rmtree(item)
            else:
                item.unlink()
        log.info("Cleared %d items from %s", len(items), dir_path)
    elif create_if_missing:
        path.mkdir(parents=True, exist_ok=True)
        log.info("Created empty directory: %s", dir_path)
    else:
        log.warning("Directory %s does not exist, create_if_missing=False", dir_path)
```

## 5. 陷阱清单

| 陷阱 | 后果 | 正解 |
|---|---|---|
| `item.is_dir()` 判断在前、`is_symlink()` 在后 | **指向目录的软链接会返回 `is_dir() == True`**，进 `rmtree` 分支：轻则报错，重则按版本差异删掉链接指向的真实目录 | 先判 `is_symlink()`，只 `unlink()` 链接本身 |
| `shutil.rmtree(dir)` 之后 `mkdir(dir)` | 丢权限、丢软链接、丢挂载点；文件被占用时半途失败，目录就没了 | 清空子项，别删目录本身 |
| `os.mkdir(path)` | 目录已存在直接抛 `FileExistsError` | `Path(p).mkdir(exist_ok=True)` |
| `Path.rmdir()` | 只能删空目录，非空抛 `OSError` | 删非空用 `shutil.rmtree` |
| 边遍历 `iterdir()` 边删 | 并发或自身删除导致迭代器失效、`FileNotFoundError` | 先 `list()` 快照 |
| 以为 `iterdir()` 不含隐藏文件 | `.gitkeep`、`.env` 会被一起删掉 | 需要保留就显式 `KEEP` 集合跳过 |
| 混淆两套 `glob("*")` | 标准库 `glob.glob("*")` **不**匹配点开头文件，`Path.glob("*")` **会**匹配 | 别靠 glob 过滤隐藏文件，显式判断 |

> 提醒：`shutil.rmtree()` 删的是**路径本身**。想「清空目录」时不要把它指向目标目录，只能指向它的子项。

## 6. 速查

| 操作 | 代码 | 安全性 |
|---|---|---|
| 创建（存在不报错） | `Path(d).mkdir(exist_ok=True)` | ✅ |
| 创建多级 | `Path(d).mkdir(parents=True, exist_ok=True)` | ✅ |
| 清空内容 | 遍历子项：软链 `unlink`、目录 `rmtree`、文件 `unlink` | ✅ |
| 删除重建 | `shutil.rmtree(d); Path(d).mkdir()` | ❌ 仅测试用 |
| 建占位文件 | `Path(p).touch()` | ✅ |
