# 文件匹配与遍历：rglob / glob

> **适用场景**：统计某个目录树下有多少个某类文件、批量挑出符合命名规则的文件、递归找散落在子目录里的产物。
> 核心是 `Path.rglob()` 递归粗筛 + `re` 精筛两层过滤。

## 1. 方案：一行统计目录树里的文件数

```python
total_files = len(list(input_dir.rglob("*.txt")))
```

拆开看：

| 部分 | 说明 |
|---|---|
| `input_dir` | `Path` 对象，如 `Path("/home/user/documents")`、`Path("data/")` |
| `.rglob("*.txt")` | **递归**匹配：`r` 是 recursive，`*` 匹配任意字符 |
| `list(...)` | `rglob()` 返回生成器，`len()` 不能直接吃，得先转列表 |
| `len(...)` | 数个数 |

`rglob` 与 `glob` 的区别只有一个——要不要进子目录：

| 方法 | 是否递归 | 用在什么时候 |
|---|---|---|
| `input_dir.glob("*.txt")` | ❌ 只当前层 | 只看这一层 |
| `input_dir.rglob("*.txt")` | ✅ 所有子目录 | 整棵目录树 |

```txt
documents/
├── report.txt
├── notes.txt
├── archive/
│   ├── old.txt
│   └── sub/
│       └── backup.txt
└── data/
    └── info.txt

# rglob("*.txt") 依次产出 5 个：
# report.txt  notes.txt  archive/old.txt  archive/sub/backup.txt  data/info.txt
```

## 2. 方案：生产写法（忽略大小写 + 省内存 + 只算文件）

```python
from pathlib import Path

input_dir = Path("your_directory")
total = sum(1 for f in input_dir.rglob("*") if f.is_file() and f.suffix.lower() == ".txt")
```

四个好处，每个都对应一个坑：

- `f.suffix.lower()` —— **绕开模式匹配的大小写差异**。`rglob("*.txt")` 的行为跟 Python 版本和平台都有关系：3.12 之前在所有平台都区分大小写，3.12+ 在 Windows 上按 NTFS 规则默认不区分。想跨版本稳定，就别依赖模式的大小写，自己比后缀；
- `sum(1 for ...)` —— 不生成列表，几万文件也不吃内存；
- `f.is_file()` —— **`rglob("*.txt")` 不看它是文件还是目录**。目录名恰好叫 `xxx.txt` 也会被捞出来，这是必须加 `is_file()` 的核心原因；
- 语义直观，一眼看出在数什么。

> `len(list(rglob(...)))` 会把全部路径一次性装进内存。几百到几千个文件无所谓，几万以上换 `sum` 写法。

## 3. 方案：通配符粗筛 + 正则精筛

通配符只能管「大致哪类文件」。文件名有明确规则时（如 `report_数字.log`），再叠一层正则：

```python
from pathlib import Path
import re

files = [f for f in Path(".").rglob("*.log") if re.fullmatch(r"report_\d+\.log", f.name)]
```

- `rglob("*.log")` 先把范围压到所有 `.log`；
- `re.fullmatch(...)` 再按名字精筛，只留 `report_20240101.log` 这一类。

> 用 `fullmatch` 而不是 `match`：`re.match` 只锚定开头，`report_1.log.bak` 也会被匹配上。要整体匹配就用 `fullmatch`，或在模式末尾加 `$`。

## 4. 陷阱清单

| 陷阱 | 后果 | 正解 |
|---|---|---|
| 目录名也叫 `*.txt` | 被当成文件统计进去，数量偏多 | 加 `f.is_file()` |
| 依赖 `rglob("*.TXT")` 的大小写行为 | 3.12 前后、Windows/Linux 结果不一致 | 用 `f.suffix.lower() == ".txt"` 自己比 |
| `re.match(r"report_\d+\.log", name)` | `report_1.log.bak` 也算命中 | 用 `re.fullmatch` |
| 大量文件仍用 `list(...)` | 内存暴涨 | 用生成器 `sum(1 for ...)` |
| 拼模式字符串时忘了转义 `.` | `*.txt` 在正则里会匹配 `xxtxt` | 正则里写 `\.`，或用 `re.escape()` |
| 用字符串拼路径再 `glob` | Windows 反斜杠被当转义 | 全程 `Path` 对象，用 `/` 拼接 |

## 5. 速查

> 递归找：`Path(d).rglob("*.ext")`；只当前层：`.glob()`；生产统计：`sum(1 for f in rglob("*") if f.is_file() and f.suffix.lower()==".ext")`；精筛：`re.fullmatch`。
