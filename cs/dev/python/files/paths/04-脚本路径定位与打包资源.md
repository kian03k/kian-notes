# 脚本路径定位：别用 CWD，用脚本自己

> **适用场景**：脚本要读写自己旁边的 `Output/`、`config.ini`、`assets/`，还要能打包成 exe 后在别人机器上照常找到这些文件。
> 一句话原则：**永远不要依赖当前工作目录定位资源，用脚本自身位置为准。**

## 1. 方案：双模式一行判断（开发 / 打包通用）

```python
from pathlib import Path
import sys

base_dir = Path(sys.executable).parent if getattr(sys, "frozen", False) else Path(__file__).parent
```

`sys.frozen` 是 PyInstaller / cx_Freeze 冻结时设的标志：

- 打包成 exe → `True` → 用 `sys.executable` 所在目录（exe 旁边）；
- 直接跑 `.py` → `False` → 用 `__file__` 所在目录。

写成一个函数更好读：

```python
def get_app_dir() -> Path:
    if getattr(sys, "frozen", False):
        return Path(sys.executable).parent
    return Path(__file__).resolve().parent

APP_DIR = get_app_dir()
OUT_DIR = APP_DIR / "Output"
OUT_DIR.mkdir(parents=True, exist_ok=True)
```

## 2. 几个定位概念的区别

| 概念 | 是什么 | 随运行位置变吗 | 该不该用来定位资源 |
|---|---|---|---|
| `__file__` | 当前 `.py` 文件的路径**字符串**（含文件名） | ❌ 不变 | ✅ 首选（源码运行） |
| `os.getcwd()` / `.` | 进程的工作目录 | ✅ 变（看从哪启动） | ❌ 禁用 |
| `sys.executable` | 解释器 / exe 的完整路径 | ❌ 不变 | ✅ 打包后用它 |
| `sys._MEIPASS` | onefile 打包后的资源解压临时目录 | 每次运行都变 | ✅ 只用于读**打进包的只读资源** |

`__file__` 只是字符串，不含目录语义，取目录要 `Path(__file__).parent` 或 `os.path.dirname(os.path.abspath(__file__))`。

### `os.getcwd()` 为什么危险

```bash
cd /home/user/Desktop/tmp          # 在 A 目录启动
python /opt/tools/report.py        # 运行 B 目录里的脚本
# 此时 os.getcwd() = /home/user/Desktop/tmp，与脚本位置毫无关系
```

同一份代码，从 PyCharm 跑、从命令行跑、被任务计划拉起、装进容器、打包成 exe，CWD 全都不一样。用它定位资源，等于把「文件在哪」交给别人决定。唯一正当用途：读用户主动指定的当前目录配置文件，或者临时脚本、交互式调试。

## 3. 方案：三种常见目录结构

### 模板 1：输出目录在入口文件旁边（最常用）

```python
def get_output_dir() -> Path:
    base = Path(sys.executable).parent if getattr(sys, "frozen", False) else Path(__file__).resolve().parent
    out = base / "Output"
    out.mkdir(parents=True, exist_ok=True)
    return out
```

不管 `python main.py`、IDE 里跑，还是双击 `myapp.exe`，都稳定落在「入口文件 / exe 所在目录 / Output」。

### 模板 2：输出目录在项目根（入口在 `src/` 里）

```txt
MyProject/
├── Output/          ← 要放这里
└── src/
    ├── main.py
    └── utils/
        └── helper.py
```

```python
def get_project_output_dir() -> Path:
    if getattr(sys, "frozen", False):
        base = Path(sys.executable).parent
    else:
        base = Path(__file__).resolve().parent.parent   # src/main.py → MyProject
    out = base / "Output"
    out.mkdir(parents=True, exist_ok=True)
    return out
```

### 模板 3：取脚本旁边的资源

```python
def resource_path(relative: str) -> Path:
    base = Path(sys.executable).parent if getattr(sys, "frozen", False) else Path(__file__).resolve().parent
    return base / relative

config_path = resource_path("config.ini")
logo_path = resource_path("assets/logo.png")
```

## 4. 方案：打包后读打进包里的资源（`sys._MEIPASS`）

`--onefile` 打包后，程序运行时把内置资源解压到一个临时目录，`sys._MEIPASS` 就是那个目录：

```python
import sys
from pathlib import Path

def bundled_path(relative: str) -> Path:
    """读打进 exe 的只读资源"""
    base = Path(getattr(sys, "_MEIPASS", Path(__file__).resolve().parent))
    return base / relative

rules = bundled_path("config/rules.json").read_text(encoding="utf-8")
```

```bash
# Windows 用分号
pyinstaller --onefile --add-data "config;config" main.py
# macOS / Linux 用冒号
pyinstaller --onefile --add-data "config:config" main.py
```

`"config;config"` 的含义：把当前目录的 `config` 打进去，运行时在 `sys._MEIPASS` 下同名可见。

### 两类资源，两种取法（最容易混的地方）

| 资源类型 | 例子 | 放置 | 取法 |
|---|---|---|---|
| 打进 exe 的**只读资源** | 规则文件、模板、模型 | `--add-data` 打进包 | `sys._MEIPASS` + 相对路径 |
| exe 旁边的**可写 / 用户文件** | 输出产物、用户配置 | 不打进包，跟 exe 放一起 | `Path(sys.executable).parent` |

用错的表现：把只读资源按「exe 旁边」取 → 打包后文件不存在；把输出写进 `_MEIPASS` → 程序退出就没了。

## 5. 陷阱清单

| 陷阱 | 后果 | 正解 |
|---|---|---|
| 用 `.` 或 `os.getcwd()` 定位资源 | 换个启动目录就找不到文件；打包后必崩 | `__file__` / `sys.executable` |
| `os.path.join("C:", "myapp", "Output")` | Windows 上得到**盘符相对路径** `C:myapp\Output`，跟随当前目录，不是绝对路径 | 盘符后必须带分隔符：`"C:/"` 或 `"C:\\"` |
| 路径用 `+` 拼或手写 `/` | 不跨平台；漏分隔符时静默拼错 | `Path / "sub"` 或 `os.path.join` |
| 资源文件没打进包 | 运行时 `FileNotFoundError` | `--add-data` 显式添加 |
| 相对路径读打包资源 | 打包后 CWD ≠ 源码目录，读不到 | `sys._MEIPASS` |
| 往 `_MEIPASS` 写文件 | 退出即丢，且 onefile 每次运行目录不同 | 可写文件走 exe 同级目录 |
| exe 放在 `C:\Program Files` | 无写权限，创建子目录失败 | 放用户目录，或用 `%LOCALAPPDATA%` |
| `--add-data` 分隔符写反 | Windows 用 `:` 会被当路径一部分，打包静默少文件 | Windows `;`，类 Unix `:` |

## 6. 速查

> 定位脚本：`Path(__file__).parent`；打包后：`Path(sys.executable).parent`；两者合一行：`Path(sys.executable).parent if getattr(sys,"frozen",False) else Path(__file__).parent`；包内只读资源：`sys._MEIPASS` + `--add-data`；拼接：永远 `/` 或 `os.path.join`。
