# 🔥 最终可用命令（直接复制运行）
## 1. Windows (PowerShell)
```powershell
tree /a /f | Select-Object -First 100 | Out-File structure.txt -Encoding utf8
```
但 **PowerShell 的 tree 不能限制层级**，所以我给你一个**更强大、能控制层级**的命令（Windows 最佳方案）：

```powershell
Get-ChildItem -Depth 3 -Directory -Recurse | Sort-Object FullName | Format-Tree | Out-File structure.txt -Encoding utf8
```
- `-Depth 3` = 只显示 **3 级文件夹**
- `-Directory` = **只显示文件夹，不显示文件**
- 自动干净、整齐

---

## 2. macOS / Linux（最完美，强烈推荐）
```bash
tree -d -L 3 -I 'assets|.obsidian|.git|test|node_modules|__pycache__' --dirsfirst > structure.txt
```

### 这条命令的含义（完全符合你的需求）
- `-d`
  只显示**文件夹**，不显示任何文件 → 超级干净
- `-L 3`
  只显示 **3 级目录**（你想显示 4 级就改成 `-L 4`）
- `-I 'assets|.obsidian|.git|test'`
  **自动过滤**：
  - assets
  - .obsidian（Obsidian 缓存）
  - .git（Git 缓存）
  - test（临时目录）
- `--dirsfirst`
  文件夹永远排在前面，结构清爽
