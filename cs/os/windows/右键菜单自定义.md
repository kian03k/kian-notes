# Windows 右键菜单自定义

> 整理自 2021 年一篇博客（在文件夹中添加"通过 Android Studio 打开项目"）。原文只讲了 Android Studio，这里抽象成通用做法——**任何程序都能这么加**。
> 一句话原理：右键菜单就是注册表里的几棵树，往对应位置写一个 `shell` 子项，菜单就多一项。

## 一、四个位置对应四种右键场景

| 右键位置 | 注册表路径 |
| --- | --- |
| 文件夹**内部空白处** | `HKEY_CLASSES_ROOT\Directory\Background\shell\` |
| **文件夹图标**上 | `HKEY_CLASSES_ROOT\Directory\shell\` |
| **任意文件**上 | `HKEY_CLASSES_ROOT\*\shell\` |
| **磁盘分区**上 | `HKEY_CLASSES_ROOT\Drive\shell\` |

区别只影响"在哪儿能右键到它"，写法完全一样。

## 二、一个菜单项由三部分组成

以新建的项名 `MyTool` 为例（项名只是标识，不显示）：

```text
HKEY_CLASSES_ROOT\Directory\Background\shell\MyTool
├── (默认)  = 用 MyTool 打开        ← 菜单上显示的文字
├── Icon    = C:\Apps\MyTool\MyTool.exe  ← 图标（可选）
└── command
    └── (默认) = "C:\Apps\MyTool\MyTool.exe" "%V"   ← 实际执行的命令
```

三个关键点：

1. 项名可以随便起（原文用 `AndroidStudio`），**菜单显示的是默认值那一串**
2. `Icon` 是字符串值（REG_SZ），填 exe 路径即可，64 位程序注意选对 exe
3. `command` 是**子项**，它的默认值才是真正执行的命令

## 三、最容易踩的坑：`%V` 还是 `%1`

| 场景 | 参数 | 含义 |
| --- | --- | --- |
| `Directory\Background\shell`（空白处右键） | **`%V`** | 当前文件夹的路径 |
| `Directory\shell`（文件夹图标右键） | **`%1`** | 被右键选中的文件夹路径 |
| `*\shell`（文件右键） | **`%1`** | 被选中的文件路径 |

原文特别强调过这个区别：**在 `Background` 下必须用 `%V`，在 `shell` 下必须用 `%1`**，用反了程序拿不到正确路径。

另外，路径含空格时整条命令要用英文半角双引号包起来，参数也一样：`"C:\Program Files\App\app.exe" "%V"`。

## 四、可直接用的 .reg 模板

把下面存成 `add-menu.reg`（UTF-8 或 ANSI 均可，**不要存成带 BOM 的 UTF-8**），改掉三处路径后双击导入：

```reg
Windows Registry Editor Version 5.00

; ===== 1. 文件夹内部空白处右键 =====
[HKEY_CLASSES_ROOT\Directory\Background\shell\OpenWithMyTool]
@="用 MyTool 打开"
"Icon"="C:\\Apps\\MyTool\\MyTool.exe"

[HKEY_CLASSES_ROOT\Directory\Background\shell\OpenWithMyTool\command]
@="\"C:\\Apps\\MyTool\\MyTool.exe\" \"%V\""

; ===== 2. 文件夹图标上右键 =====
[HKEY_CLASSES_ROOT\Directory\shell\OpenWithMyTool]
@="用 MyTool 打开"
"Icon"="C:\\Apps\\MyTool\\MyTool.exe"

[HKEY_CLASSES_ROOT\Directory\shell\OpenWithMyTool\command]
@="\"C:\\Apps\\MyTool\\MyTool.exe\" \"%1\""
```

> 注意 `.reg` 里反斜杠要写成 `\\`，这是文件格式要求，不是笔误。

## 五、只想按住 Shift 才显示

在 `shell\MyTool` 下加一个空字符串值 `Extended`：

```reg
[HKEY_CLASSES_ROOT\Directory\Background\shell\OpenWithMyTool]
"Extended"=""
```

这样菜单平时不占地方，按住 Shift 右键才出现。

## 六、删除菜单项

直接删掉对应的 `shell\MyTool` 整项即可，重启资源管理器（任务管理器里重启 `explorer.exe`）后生效。

或者命令行：

```bat
reg delete "HKEY_CLASSES_ROOT\Directory\Background\shell\OpenWithMyTool" /f
reg delete "HKEY_CLASSES_ROOT\Directory\shell\OpenWithMyTool" /f
```

## 七、原文的具体例子（Android Studio）

| 配置项 | 值 |
| --- | --- |
| 项名 | `AndroidStudio` |
| 显示文字 | `Open Folder as AndroidStudio Project` |
| Icon | `D:\Program Files\Android\Android Studio\bin\studio64.exe` |
| command（Background） | `"D:\Program Files\Android\Android Studio\bin\studio64.exe" "%V"` |
| command（shell） | `"D:\...\studio64.exe" "%1"` |

## 八、Win11 注意事项

Windows 11 的**新版右键菜单**（圆角那套）不会显示这类注册表项。要看到得点"显示更多选项"，或者按住 `Shift` 再右键。

想让它直接出现在新菜单里，得走 `IExplorerCommand` 的 COM 扩展，那是另一个量级的工程，为一个菜单项不值得。日常用 Shift 右键就行。
