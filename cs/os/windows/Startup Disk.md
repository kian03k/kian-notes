# 补充-Q&A

### 选择分区类型

目标系统类型

GPT分区

UEFI(Unified Extensible Firmware Interface),统一可扩展硬盘接口，性能更好，2012年之后逐渐普及，默认选此即可。

如果重装时提示：ERROR:BIOS/LEGACY BOOT OF UEFI-ONLY MEDIA。改为MBR分区。

BIOS/Legacy:搭配MBR分区，最多支持4个分区，2.2T硬盘容量，但适配性好，适合旧电脑。

查看电脑是否支持UEFI的方法

- 查看BIOS设置：重启电脑，按特定按键（常见如Del、F2等，不同品牌型号电脑按键不同）进入BIOS界面。若在BIOS界面中能看到“UEFI”相关选项（如UEFI启动模式、UEFI Boot等），或者有“Legacy”与“UEFI”两种启动模式可切换，说明电脑支持UEFI。
    
- 在操作系统中查看：在Windows系统中，按下“Win + R”组合键打开运行窗口，输入“msinfo32”并回车，打开系统信息窗口。在“系统摘要”中，查看“BIOS模式”，若显示为“UEFI”，则表明电脑当前以UEFI模式启动，也就支持UEFI；若显示为“传统”，则说明当前是BIOS/Legacy模式启动，但也不排除电脑硬件支持UEFI只是未启用的情况。

### 选择文件系统（默认NTFS)

名词解释

NTFS

簇大小 Allocation Unit Size

用于存储文件的最小单位，即无论文件多小至少占用一个簇的空间，小簇可以更高效存储大量小文件，减少空间资源浪费，大簇适合存储大文件，提升磁盘操作性能。默认4KB,可根据实际情况修改，改为8KB,16KB都可，普通用户影响不大。

## 补充学习信息（感兴趣可以看）

1.BIOS/Legacy和UEFI两种启动方式下安装的系统有以下差异：

1. 分区结构
    

- BIOS/Legacy：通常搭配MBR分区。MBR分区最多支持4个主分区或3个主分区加1个扩展分区（扩展分区可划分多个逻辑分区），受限于主引导记录的512字节空间，最大支持约2.2TB的硬盘容量，超过此容量部分无法利用。
    
- UEFI：多采用GPT分区。GPT分区突破了分区数量限制，理论上可创建128个主分区，还支持更大容量硬盘，提供了更好的磁盘空间管理与数据保护能力，如备份分区表、循环冗余校验等。
    

2. 启动文件位置与加载
    

- BIOS/Legacy：启动文件存放在主引导扇区，启动时BIOS按固定顺序查找引导设备（如硬盘、光盘等），找到主引导记录后加载其中的引导代码，再由引导代码加载操作系统内核。
    
- UEFI：启动文件存储在ESP（EFI系统分区），UEFI固件可直接读取ESP分区中的启动文件，按UEFI设置的启动顺序启动系统，无需像BIOS那样依赖主引导记录，加载速度更快。
    

3. 系统兼容性
    

- BIOS/Legacy：对一些较老的硬件和操作系统支持较好，如Windows XP等系统只能在BIOS/Legacy模式下安装。但对于新型硬件和大容量存储设备的支持存在局限。
    
- UEFI：更适应现代硬件和操作系统，尤其适用于64位系统，如Windows 10、Windows 11等。不过在一些非常老旧的硬件上可能无法使用。
    

4. 安全性
    

- BIOS/Legacy：安全性较弱，缺少有效的安全启动机制，恶意软件易篡改引导记录，导致系统启动故障或安全问题。
    
- UEFI：具备安全启动功能，仅允许加载经过数字签名认证的操作系统和驱动程序，防止恶意软件在启动阶段入侵，提高系统安全性。
