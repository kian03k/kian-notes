# 电脑管理与检测工具

## 工具箱

- **Dism++** — Windows 系统维护全能工具箱，清理、优化、映像管理

## 硬盘

### CrystalDiskInfo

硬盘 / SSD 健康检测工具。读取硬盘自身的 S.M.A.R.T. 数据，用颜色直接标出健康状态，能看温度、通电时间、通电次数和累计写入量。买二手盘、排查"电脑变卡是不是盘要坏了"，第一个就该看它。

| 项 | 内容 |
| --- | --- |
| 官网 | https://crystalmark.info/en/software/crystaldiskinfo/ |
| 下载页 | https://crystalmark.info/en/download/ |
| 源码 | https://github.com/hiyohiyo/CrystalDiskInfo |
| 授权 | MIT，开源免费 |
| 平台 | Windows 7 / 8 / 10 / 11（含 Server） |
| 本机版本 | **8.17.14**，安装包名 `CrystalDiskInfo8_17_14.exe`（zip 是便携版） |

> 官网当前主版本已到 **9.x**，8.17.14 是稳定老版本。老版本够用，不必追新；如果新硬盘识别不出来，再升到 9.x。

**版本怎么选**：Standard / Shizuku / Kurei Kei 三个版本的**功能完全一样**，后两个只是换动漫人物皮肤。日常用 Standard。

**装哪个包**：

| 包 | 特点 |
| --- | --- |
| `CrystalDiskInfo8_17_14.exe` | 安装版，写注册表，可开机自启 |
| `CrystalDiskInfo8_17_14.zip` | **便携版**，解压即用，适合放 U 盘随身带 |
