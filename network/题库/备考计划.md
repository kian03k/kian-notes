# 备考计划（7 天）

> 照着做就行。每天 1–1.5 小时，勾掉一项划一项。相关笔记见 [[面试总览与答题策略]]。

## 总原则

**这不是"重新学"，是"重建索引"。**

忘掉的是术语和框架，不是判断力。一旦把"ping 时好时坏"和"ECMP 哈希"对上号，经验就回来了。所以：

- ❌ 不要从第一页顺序读到最后一页
- ✅ 用**自己的项目反查**（见下文"高效方法"）
- ✅ 只背**不能推理**的东西（见"必背五样"）

**节奏参考**：3 天能应付面试，2 周扎实，1 个月不慌。

## 必背五样（只有这些需要死记，其余都能推）

- [ ] **1. OSPF 七态顺序**：Down → Init → 2-Way → ExStart → Exchange → Loading → Full
  - 卡 Init = 单向；卡 ExStart = MTU；卡 2-Way = 正常（DROther 之间）
- [ ] **2. LSA 类型**：1 拓扑 / 2 网段 / 3 区域间 / 4 ASBR / 5 外部 / 7 NSSA
- [ ] **3. BGP 六态**：Idle → Connect → Active → OpenSent → OpenConfirm → Established
  - **Active = 连接失败在重试**，不是进行中
- [ ] **4. BGP 选路骨架**：Local_Pref → 本地始发 → AS_Path → Origin → MED → eBGP>iBGP → IGP 开销 → Router ID → 老路由
- [ ] **5. EVPN 五类**：1 快速收敛 / 2 MAC-IP / 3 BUM / 4 DF / 5 IP 前缀

**命令一个都不用背。** 面试说"用 `display ospf peer` 看邻居状态"就够，现场查手册。

## 高效方法：用项目反查（比顺序读快三倍）

顺序读是从零建框架；反查是把框架挂到已有记忆上。**每对上一个，就是一整块经验被激活。**

**做法**：打开自己的项目，对着原理笔记问自己——

| 问自己 | 对着看哪节 |
|---|---|
| 我们配了 PFC 吗？什么优先级？ | [[RoCE与无损网络]] 第三节、第九节 |
| 有没有遇到过训练突然变慢？当时怎么查的？ | 同上，第八节（慢节点定位） |
| 客户问为什么要分五个平面，我怎么答的？ | 同上，第六节 |
| 参数面为什么不走 VXLAN？ | 同上，第十节 |
| 割接前我核对了哪些东西？ | [[综合场景与排障题库]] 第 24 题 |
| 交付节奏为什么是网络先通？ | 同上，第 28 题 |
| 交换机是 M-LAG 还是堆叠？peer-link 带宽多少？ | [[M-LAG与高可用组网]] 三、四节 |

**答不上来的，就是你要补的。**
