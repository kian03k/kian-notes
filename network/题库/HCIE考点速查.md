# HCIE 考点速查

零散考点与判断题的核对结论。每条给出结论与依据，原稿中的错误已就地更正。

## 一、路由与策略

### 策略路由重定向的生效方向

**判断**：策略路由通过流行为中的重定向实现，对接口入、出方向的报文均生效。—— **错误**

**结论**：重定向仅在**入方向**生效。

**依据**：VRP 流策略中，接口出方向可执行的动作限于流量统计、重标记（remark）、丢弃、队列调度等；重定向会改变报文的转发出接口与下一跳，必须在报文进入设备后、转发查表前完成，因此只支持在入方向应用。

> 修正：原稿只给出答案 False，未说明原因。此处补入方向限制的依据。

### OSPF 与 BGP 的防环机制

| | OSPF | BGP |
|---|---|---|
| 协议类型 | 链路状态 | 路径矢量 |
| 核心防环 | SPF 算法 + 区域层次化 | AS_PATH 检查 |
| 环路检测 | Dijkstra 计算最短路径树，天然无环 | 收到含自身 AS 号的路由即丢弃 |
| 辅助机制 | 非骨干区域必须挂 Area 0、LSA 序列号与老化 | iBGP 水平分割（全互联或路由反射器）、联盟 |

三个容易混淆的点：

1. **BGP 选路不是防环机制。** Weight、Local Preference、MED、Origin 等属性用于在无环的候选路径中择优，不承担防环职责。原稿把"路由优选规则"列为防环手段，属于概念错误。
2. **ABR 的通告方向。** ABR 从骨干区域学到 Type 3 后向本非骨干区域通告，反向亦然；它不会把某个非骨干区域的 Type 3 再转给另一个非骨干区域。原稿"只向 Area 0 通告汇总路由"方向说反了。
3. **eBGP 没有水平分割这个机制。** eBGP 收到路由后 AS_PATH 会追加自身 AS 号，来源邻居再次收到时因 AS_PATH 含自身 AS 而丢弃，效果等同水平分割，但机制是 AS_PATH 检查。真正的水平分割规则在 iBGP：**从 iBGP 邻居学到的路由不再通告给其他 iBGP 邻居**，这也是 iBGP 需要全互联或 RR 的原因。

## 二、交换与 WLAN

**SSID 与 BSSID**

- SSID 是无线网络名称，用于区分不同 WLAN。
- BSSID 是 AP 射频口的 MAC 地址，用于唯一标识一个 BSS。

**WLAN 加密算法强度**

在 WEP / TKIP / CCMP 三者中，CCMP（AES-CCMP）强度最高。

> 注：802.11ac 之后引入 GCMP-256（WPA3 使用）。若题目限定在上述三种传统算法内，答案仍为 CCMP。

**LACPDU 携带的信息**

Actor 侧的系统优先级、系统 MAC、端口优先级、端口号、操作 Key（Operational Key）。

> 补充：LACPDU 同时携带 Actor 与 Partner 两侧的上述信息，不含端口速率；速率由两端 LACP 计算后确定。

## 三、IPv6

**接口标识长度**

链路本地单播地址由 `FE80::/10` 前缀、54 位全零子网字段、64 位接口标识构成。**接口标识固定 64 bit**，与地址类型无关。

**EUI-64 生成接口标识**

1. 取 48 位 MAC 地址；
2. 在 OUI 与厂商扩展 ID 之间插入 16 位 `FFFE`；
3. 将第一字节的第 7 位（U/L 位）取反；
4. 与前缀拼接成 128 位地址。

## 四、设备管理与诊断

**SNMP 告警端口**

Agent 主动向 NMS 发送 Trap / Inform 时使用目的端口 **162**；Agent 自身监听 **161** 接收 Get/Set 请求。

**ping 指定源地址的参数**

```
ping -a <源IP> <目的IP>
```

> 修正：原稿写作 `ping -s <源IP> <目标IP>`，错误。VRP 中 `-s` 是报文净荷长度（packetsize），不是源地址。
